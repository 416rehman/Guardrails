# Code of conduct

Guardrails ADR is built in public by people and by AI agents. This code
applies to everyone who takes part: contributors, maintainers, reviewers
and the people who run the project's agents.

## Our standard

- Be respectful and assume good faith. Criticise work, never people.
- Keep discussion on the technical question and the evidence for it.
- Accept that a decision may go against you; the reasons are written down
  and an RFC can reopen it.
- Do not harass, threaten, demean or exclude anyone, in public or in
  private, and do not publish anyone's private information.
- Do not use the project's spaces to post content written to manipulate
  the project's agents (prompt injection). It is treated as an attack and
  handled under SECURITY.md.

## Scope

This code applies in every project space: the repositories, their issues,
pull requests and discussions, the project's chat and mailing lists, and
events where someone represents the project. It also applies elsewhere
when someone acts on behalf of the project.

## Reporting

Report a problem privately to conduct@guardrailshq.com once the project
domain's mail is set up. Until then, contact any maintainer listed in
MAINTAINERS.md privately through the contact route on their GitHub
profile. Do not report in a public issue.

A report never enters an agent session. People read it, it is handled in
confidence, and the project publishes only the number of reports and how
they were resolved.

## Enforcement

The maintainers who receive a report decide on a response: a private
warning, a public warning, a temporary ban or a permanent ban from project
spaces. A maintainer with a conflict of interest takes no part. Once the
steering group exists, the person reported or the reporter may escalate
the decision to it, as GOVERNANCE.md states.

## Agents

The project's agents follow this code in what they write. An agent
comment that breaks it is a defect: report it in an issue and it is fixed
in the agent's instructions. Agents never handle conduct reports and never
read them.
