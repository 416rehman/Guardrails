# 2026 conference work on securing AI agents: catalogue and defensive requirements

_Researched 2026-11-10 (search-backed follow-up)_

Method: 18 web searches (2 extended) plus direct fetches. Tags: **[P]** primary page read today (programme, advisory, vendor write-up, repo); **[L]** DEF CON 34 schedule export (HackerTracker format, 1,547 items, 112 official talks) found in this run's shared scratchpad and cross-checked against aivillage.org and press coverage; defcon.org itself still resets connections; **[S]** secondary (recap, vendor blog, community index); **[M]** from memory. Black Hat's site returned 403; Black Hat titles come from a slide index with official session links [L] and a vendor round-up [S]. Findings are recorded conceptually; no payloads were collected.

## TL;DR

- The programmes are now in hand. DEF CON 34 (6 to 9 Aug 2026) had about 150 agent-related sessions; Black Hat USA 2026 (briefings 5 and 6 Aug) had roughly 35 AI talks of 121 [S]; BSides Las Vegas hosted an "[un]prompted" track; the AI Village ran 34 posters, most on agents.
- **Agent sandboxes fail at the seams, not the kernel.** Novee broke Claude Code, Gemini CLI and Codex CLI by design gaps: allow rules evaluated after safety checks, an allowlist checked at registration but not at execution, a Landlock backend that silently dropped read-only exceptions, a shared `/proc` and `/tmp`, and a trusted parent process. Gemini's issue scored CVSS 10.0 and fired before any prompt.
- **Observability and security tools are now injection carriers.** Tenet's "GhostJacking" turned WAF-blocked requests and unauthenticated Sentry events into instructions that agents later read through MCP; one agent then infected another. No single vendor fix exists.
- **LLM guards leak.** BeyondTrust used Copilot Studio's guard model as an oracle (non-deterministic, reasoning exposed); "Block Means Yes" shows a correct guard still leaks secrets one bit per verdict; Check Point's "LGTM" bypassed an LLM build gate by putting the dangerous part where the model could not look.
- **Gateways are Tier-1 targets.** Wiz's "OffGuard" chained an MCP auth bypass (CVE-2026-59822, in CISA KEV since 2 Sep 2026) with root code execution through LiteLLM's custom-code guardrails (CVE-2026-59821); 9.6% of 3,074 exposed instances accepted the default key.
- **Multi-agent propagation is measured, not hypothetical.** MCParasite propagated across shared channels in 21 of 26 tests; Pillar showed one CI agent waking another by mention; an A2A reference field bypassed ownership checks; Zenity pulled 1,000+ agents in 70+ countries with one feed post.
- **Agentic browsers reopen the pre-2008 web.** Zenity's PleaseFix hit all five major agentic browsers; vendor responses split between "patched" and "intended".
- **Skills are malware without binaries.** MalSkill showed five benign skills composing into an exfiltration path and a skill that persists in agent memory after deletion; 700+ malicious skills reached ClawHub within weeks.
- **Approval is weak evidence.** Posters and talks measured rubber-stamping, approval prompts that omit upstream provenance, and eight human checkpoints cleared by one poisoned product description.
- **Defensive open source arrived at the same events**: AgentsLeak, GolemHalt (Cedar hooks), HoneyMCP, MCP X-Ray, AgentHound, Praxis, Splunk SIEMulator, a Roblox reference architecture, and an on-device judge using Endpoint Security (OBTS, 18 Nov).
- Academic venues now centre on least privilege for skills, MCP contract auditing, causal attribution and memory defences (CCS 2026 has 17 agent papers by title).

## Implications for our design

1. **Ship a sandbox conformance suite.** For every declared boundary on every backend (Landlock, bubblewrap, Seatbelt, Windows), a test proves enforcement at execution time, including pre-task inputs, headless runs, shared `/proc` and `/tmp`, and parent-trusts-child paths.
2. **Source-trust labels on tool results.** The MCP gateway tags results from telemetry-class connectors (WAF logs, error trackers, tickets, issues) as untrusted and blocks state-changing calls whose arguments derive from them without step-up.
3. **Harden our own LLM consumers first.** Our console assistant, triage agents and detonation workers read attacker-written fields; quote fields, strip reasoning from outputs, isolate workers per tenant with no credentials and no egress.
4. **Gateway as Tier-1.** No default keys, fail closed, no in-process execution of user-supplied guardrail code, credential bound to destination, egress validation, continuous KEV matching of gateways we discover.
5. **Judge hygiene.** Verdict code only, feedback rate-limited, probing detection, deterministic policy beneath, and a rule that a judge refuses when it cannot see everything the action depends on.
6. **Cross-agent graph.** Build the AgentHound graph from our inventory (configs, credentials, MCP servers, instruction files, shared channels) and detect new paths, agent-to-agent triggers and content written by one agent then acted on by another.
7. **Skills and MCP supply chain.** Baseline and diff tool descriptions after approval, analyse skill composition, flag run-time remote fetches, detonate at install.
8. **Browser sensor priorities.** Mark agent-driven sessions and gate purchases, password-manager access and collaborator changes in the five agentic browsers.
9. **Credential-layer control.** Offer an out-of-process broker for cloud tokens with blast-radius policy; detect role-assignment writes by agent identities.
10. **Approval quality as a metric.** Show argument provenance in approvals, measure approval latency, and use predict-then-approve for irreversible actions.

**Ten talks that most change what we build:** (1) The Sandbox Is a Suggestion; (2) No Prompt Required; (3) Your WAF Blocked Us; (4) OffGuard; (5) Wrestling with a Python, with Block Means Yes; (6) PleaseFix; (7) MalSkill, with Promptware EOD; (8) MCParasite, with "I'll just call you"; (9) Breaking MCP Trust Boundaries, with Agenthound; (10) Caging the Agent, with Naughty or Nice as the endpoint counterpart.
