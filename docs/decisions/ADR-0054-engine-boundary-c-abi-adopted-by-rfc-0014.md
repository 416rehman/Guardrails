## Context
WI-0016 (`#19`) adds the slice-0 engine boundary across protobuf package `grdr.embed.v1alpha1` (`#381`), layer 1 module `grdr_core::engine` and vectors (`#384`), C ABI `0.1` in `grdr-ffi` (`#388`) and `wasm32` exports in `grdr-wasm` (`#19`). Under D-61, public crates (`grdr-core`, `grdr-ffi`, `grdr-wasm`, `grdr-proto`, `grdr-model`) and wire formats change only by RFC, and new dependencies always escalate. Prior to RFC 0014, seven mismatches separated `#381`, `#384`, `#388` and `#19` from settled repository contracts: bare `Envelope` vs `grdr.event.v1alpha1.Event` (`#394`), informal `metadata` wording instead of RFC 0006 `DataClass` options alongside missing `StepId`, `Output` safety under ADR-0041 constraint 1d on failed entropy draws, `VerifiedBundle::assume_verified` ingress across FFI/`wasm32` without a Layer-1 `grdr-crypto` edge or `grdr-core` bypass (`ARCH-006`, `ARCH-012`), `InterestSet` binary framing against `spec/host-contract/tables.md` section 3.5, `grdr_engine_config.struct_size` (`uint32_t` base size `4`, `#246`) and shared 12-code `grdr_status` (`GRDR_E_CHANGED = 11`, RFC 0005), and Edition 2024 `unsafe_code = "forbid"` conflicts on `grdr-wasm` `#[unsafe(no_mangle)]` exports alongside `grdr_alloc` returning `grdr_status`.

## Decision
**Accepted.** The slice-0 engine boundary across `grdr.embed.v1alpha1`, `grdr_core::engine`, C ABI `0.1` (`grdr-ffi` / `grdr.h`), `wasm32` exports (`grdr-wasm`), test dependencies and `experimental` stability classes is RFC 0014 at pre-acceptance reviewed blob `7672ed44b1ffbc0248ec75d5540fff5e39c4171c` (SHA-256 `e383c44034f22e644fefdd6c9752ba026c09681f021f5a59475aae023aad1c77`), written against spine pin `a80859235e7a2a4444648d6fa8d389d78dde6be9` (SHA-256 `8f6ea876777c0121ecec068c0bc4cef45932be45c1c2aff4140712db1e06628d`) ([RFC 0014, Design](../../rfcs/0014-engine-boundary-c-abi.md#design)). In outline:

1. **Protobuf skeleton `grdr.embed.v1alpha1` (`proto/grdr/embed/v1alpha1/engine.proto`, R1).**
   - Declares `Input` (`oneof kind { grdr.event.v1alpha1.Event event = 1; Tick tick = 2; }`, reserving `3..5` for `action_request`, `grant`, `response_command`), `Tick`, `Output` (`step_seq`, `step_id`, `events` of `grdr.event.v1alpha1.Event`, `effects`, `diagnostics`, reserving `6` for `decision`), `Effect` (reserving `1..4` for `expectation`, `actuator_request`, `label_projection`, `interest_change`), `Diagnostic` (`code`, nested `Severity` `SEVERITY_UNSPECIFIED..SEVERITY_ERROR` with `wire_name`, `rule_id`), `LoadReport` (`bundle_digest`, nested `NotEvaluable`), `EngineState` (`format_version`, `bundle_digest`, `step_seq`) and minimal `HostProfile` (`host_id`, `host_version`, reserving `3..8` for EM-8).
   - Every field carries an RFC 0006 `DataClass` option (`DATA_CLASS_IDENTIFIER` on `step_id`, `bundle_digest`, `host_id`; `DATA_CLASS_STRUCTURAL` on all remaining fields; zero `content` embed-wrapper fields under P8). `Diagnostic.code` carries registered `GRDR-<AREA>-<NNNN>` identifiers only with zero human prose strings (P8, D-69). Unset `Input.kind` fails boundary decoding with `BoundaryError::DecodeInput` (`GRDR_E_DECODE`), leaving state unchanged.

2. **Rust layer 1 boundary in `grdr_core::engine` and `grdr_model` (R2).**
   - `grdr-model` gains `VerifiedBundle` (`crates/grdr-model/src/bundle.rs`) and `StepId` (`IdKind::Step`, prefix `"stp"`, `MintRoute::Uuid7`, `loggable = false` as content under RFC 0009 section 4 and [ADR-0041](ADR-0041-the-grdr-model-slice-0-surface-adopted-by-rfc-0009.md)).
   - `crates/grdr-core/src/lib.rs` exports `pub mod engine;` exposing `Engine::{load, step, interest, snapshot, restore}`, `HostProfile`, `LoadReport`, `NotEvaluable`, `Input<'a>`, `Output::{Completed(StepOutput), Failed(StepFailure)}` (`#[non_exhaustive]` enum satisfying `docs/design/03` section 3 and ADR-0041 constraint 1d so failed entropy draws, invalid `Timestamp`, or `step_seq` overflow return typed failures leaving `step_seq` intact), `Effect`, `Diagnostic`, `Severity`, `InterestSet` (using `grdr_fastpath::layout` types), `StateSnapshot` (`FORMAT_VERSION_V1 = 1`), `LoadError`, `StepError` and `BoundaryError`, backed by `GRDR-CORE-0001`..`0009` in area `CORE` (`schema/codes/areas.toml`, `schema/codes/core.toml`, RFC 0007 and [ADR-0044](ADR-0044-code-tokens-before-the-token-check-adopted-by-rfc-0010.md)).
   - `grdr_core::engine::boundary` provides the single codec path (`load`, `step_bytes`, `timestamp_from_unix_ns`, `interest_bytes`, `snapshot_bytes`, `restore_bytes`, `encode_diagnostic`) over `&VerifiedBundle` with fixed 28-byte-header `GRDI` v1 framing for `InterestSet`, plus unkeyed pure checked-Rust FIPS 180-4 digest `bundle_sha256` in `crates/grdr-core/src/engine/bundle_sha256.rs` (zero `unsafe`, zero third-party crypto crates, verified by NIST CAVP vectors in `#384` and Layer 2 -> Layer 1 differential tests against AWS-LC in `#337` / `crates/grdr-crypto/tests/`). `VerifiedBundle::assume_verified` is strictly confined by `ARCH-012` outside tests to `grdr-crypto`, `grdr-update`, `crates/grdr-ffi` and `crates/grdr-wasm`, and never called inside `grdr-core`.

3. **C ABI `0.1` in `grdr-ffi` and `grdr.h` (R3).**
   - Exports 13 functions (`grdr_abi_version() == 0x0000_0001`, deferring `grdr_engine_compile_fastpath` to `0.2` via `#1918`). Accepts the departure from `docs/design/26` section 3: `grdr_engine_config` carries `{ uint32_t struct_size; }` (base size `4`, matching `spec/host-contract/c-abi.md` `#246`), deferring `alloc`, `realloc`, `free`, `alloc_ctx`, `memory_cap` and `step_budget` behind `struct_size` until EM-6.
   - Declares the shared 12-code `grdr_status` block (`0..11`, including RFC 0005's `GRDR_E_CHANGED = 11` behind `#ifndef GRDR_STATUS_DEFINED`), explicit `HandleState::{Created, Loaded, Poisoned}`, bounded `Vec::try_reserve_exact` + `bundle_sha256` + `VerifiedBundle::assume_verified` at `grdr_engine_load` / `grdr_engine_restore`, `Send + !Sync` guarantees with zero global mutable state, `catch_unwind` -> `Poisoned` / `GRDR_E_INTERNAL`, RFC 0004 `grdr_abi.rs` / `header_drift` via `grdr-cabi-testkit` (`#1778`), and `[lib] crate-type = ["rlib", "staticlib"]` with `tests/c_harness.c`.

4. **`wasm32` core exports in `grdr-wasm` (R4).**
   - Compiles one `wasm32-unknown-unknown` `cdylib` with an empty import section (`module.imports().next().is_none()`), exporting `memory` (maximum capped from `limits.toml`, `64 MiB` = `1,024` 64 KiB pages), `grdr_alloc(len: u32) -> grdr_status`, `grdr_free`, `grdr_buf_free`, `grdr_result_ptr`, `grdr_result_len` and the 13 engine exports over linear memory.
   - Stateful/allocating exports pre-poison `InstanceSlot::TrapPoisoned` on entry via `core::mem::replace` across `panic = "abort"` / `--max-memory` traps, treat `len == 0` spans (including `grdr_engine_interest(0, 0)`) as `&[]` without requiring a slot entry, enforce `EMBED_WASM_MEMORY_MAX` + decode/copy headroom + `Vec::try_reserve_exact` (`GRDR_E_RESOURCE` preserving `last-known-good`, verified by a hostile `33 MiB` vector), and isolate 100% of implementation inside `mod safe_impl { #![forbid(unsafe_code)] ... }` under single-call `#[unsafe(no_mangle)]` wrappers gated by `#1751`'s `ARCH-027` `syn` AST check.

5. **Dependencies, CI harness and stability/trust-core routing (R5, R6).**
   - **R5 (a):** Admits `wasmi = "=2.0.2"` (`MIT OR Apache-2.0`, `default-features = false`, `features = ["stable", "std", "validate", "auto-dispatch"]`, SHA-256 `8762bb61dfbcfdbe0ab1a783a73d26d5149809cf7d882c9c9b76b7c0fb9417de`) strictly as a `[dev-dependencies]` entry of `crates/grdr-wasm/Cargo.toml`, blocked in `Cargo.lock` until its 7-day cooldown `not_before = "2026-11-26T14:25:11Z"` clears (`hashbrown 0.17.1` satisfied or `0.17.2` after `2026-11-25T01:08:02Z`; `#2080`, `#19`). Rejects `wasmtime`.
   - **R5 (b):** Cites accepted [RFC 0004](../../rfcs/0004-c-header-generation-and-drift-check.md) ([ADR-0034](ADR-0034-c-headers-are-generated-by-each-ffi-crates-drift-test.md)); zero header generator crate added.
   - **R5 (c):** Runs EM-4's C harness as a plain command step inside `.github/workflows/verify.yml`'s `c-headers` job (`#1779`) across `gcc` and `clang` (`ubuntu-26.04`), Apple `clang` (`macos-26`) and `MSVC` (`windows-2025`), rejecting the `cc` crate.
   - **R6:** All new surfaces start **`experimental`** (`D-60`, `ADR-0020`), added through `#2078` in [`surfaces.toml`](../../surfaces.toml) (`[[proto_package]] package = "embed.v1alpha1"` once RFC 0006 `#1848` settles `[[proto_package]]`, plus `[[crate]]` rows for `grdr-ffi` and `grdr-wasm`); `crates/grdr-wasm/**`, `crates/grdr-core/src/engine/bundle_sha256.rs` and `crates/grdr-core/src/engine/bundle_sha256/**` enter [`security/trust-core.paths`](../../security/trust-core.paths) through `#2079`.

6. **No pin and no evidence.** RFC 0014 decides no pinned path. [`rfcs/pins.toml`](../../rfcs/pins.toml) stays unchanged at `docs/design/00-decisions.md` blob `a80859235e7a2a4444648d6fa8d389d78dde6be9` (`sha256` `8f6ea876777c0121ecec068c0bc4cef45932be45c1c2aff4140712db1e06628d`), and no file is added under `rfcs/evidence/` ([RFC 0001](../../rfcs/0001-adopt-the-spine.md#design); [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).

7. **What this acceptance binds.** Changing `grdr.embed.v1alpha1` skeleton field semantics/numbers incompatibly, changing public signatures/enums/wire framing (`GRDI` v1, 13-export C ABI `0.1`, 18-export `wasm32` ABI) in `grdr_core::engine`, `grdr-ffi`, `grdr-wasm`, promoting any of these surfaces out of `experimental`, or adding a runtime Wasm/C dependency requires an amending RFC naming RFC 0014. Adding `CORE` error codes follows RFC 0007 section 4 (`ADR-0038`) and RFC 0010 (`ADR-0044`); adding `StepId` (`stp_`) follows RFC 0009 section 4 (`ADR-0041`); introducing the `[u8; 32]` seeded product `Entropy` implementor before `#388` and `#19` execute requires `#2083` amending RFC 0008 and RFC 0009 (`ADR-0041` constraint 2e).

## Alternatives rejected
- Those of [RFC 0014, Alternatives](../../rfcs/0014-engine-boundary-c-abi.md#alternatives).
- Adding a pin record or `rfcs/evidence/` files: RFC 0014 changes no pinned path ([RFC 0001](../../rfcs/0001-adopt-the-spine.md#design); [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).
- Editing RFC 0014's reviewed `Summary`, `Motivation`, `Design`, `Surfaces changed`, `Alternatives`, `Drawbacks` or `Unresolved questions` text on acceptance: RFC 0001 ("Review binds the decision") and RFC 0014 `## Review` permit changing only `State:`, `Decision record:`, review link lines and `## Decision`.
- Admitting `wasmi = "=2.0.2"` into `Cargo.lock` or `supply-chain/admissions.toml` during acceptance: rejected because `wasmi 2.0.2` (`2026-11-19T14:25:11Z`) sits inside its 7-day `not_before = "2026-11-26T14:25:11Z"` cooldown (`docs/design/35` section 2.6, `S04`) and is routed through `#2080`.
- Solving ADR-0041 constraint 2e inside RFC 0014 or allowing `crates/grdr-wasm` `unsafe_code = "deny"` without `mod safe_impl { #![forbid(unsafe_code)] }` and `#1751` AST enforcement: rejected by ADR-0041 (`RFC 0008` + `RFC 0009` amendment requirement) and `eval-security` Round 1 review.
