## Context
D-61 places every change to a public layer 2 crate's API through the RFC route ([ADR-0001](ADR-0001-decisions-are-adrs-and-public-surfaces-change-by-rfc.md), [ADR-0020](ADR-0020-stability-classes-live-in-surfaces-toml.md), [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)). Seven slice-0 items (`#374`, `#375`, `#555`, `#1549`, `#1606`, `#683`, `#684`) built `grdr-wire`'s framing, local transport and peer-authentication items without one, leaving conflicting trait designs and unaddressed OS boundaries: forgeable verifier traits (`#374` R4), duplicated resolvers (`#374` R3 and `#516` R1), Unix socket-mode refusals that reject world-writable Protected sockets needed for `connect(2)` (`#375`), single-directory checks vulnerable to ancestor rename (`#375`), ineffective Windows pid re-reads and standard-user `OpenProcess` failures (`#555`), client-side Unix peer-executable checks incompatible with service-manager socket activation (`#464`), and local connect/read waits lacking bounded deadlines ([RFC 0003, Motivation](../../rfcs/0003-grdr-wire-surface.md#motivation)).

At the same time, [ADR-0045](ADR-0045-daemon-os-calls.md) (`Status: proposed`, from `#1743` and `#1671`, synced to [`docs/design/03-system-architecture-and-modularity.md`](../design/03-system-architecture-and-modularity.md) by `#2011`) moved OS `unsafe` bindings into layer 3 OS adapter crates (`grdr-os-service` and `grdr-peer-os`), requiring a clean `unsafe`-free seam in `grdr-wire`.

## Decision
**Accepted.** Adopt the slice-0 surface, seams, decision tables, bounded waits, 22 error codes (`GRDR-WIRE-0001..0011` and `GRDR-PEER-0001..0011`), evidence/audit rules, 8 `limits.toml` seed bounds, `experimental` stability classes, and `ARCH-028` / section 15 amendments stated in [RFC 0003](../../rfcs/0003-grdr-wire-surface.md) as reviewed at blob `16f0e68e3ef5be431236a161fa9dc9e76dd8f7f5` (commit `118f6205c53ebc64665f1853ca8267599b9c61b6`, merged at `4252a9932ba8b25b00fb82b5050f9f3a718ffe49`) against spine commit `a80859235e7a2a4444648d6fa8d389d78dde6be9`.

1. **Crate boundaries and `unsafe`-free core (Rules 1 to 2, 6; section 2).**
   - **`grdr-wire`** (`layer = 2`, public, `experimental`, `#2063`): exports `frame`, `local` (with `local::conformance`), and `peer_auth` (`trust-core`). Depends solely on `grdr-schema` (layer 0), `grdr-model` (layer 1, for `Monotonic`, `LogSafe`, `InstallProfile`, `Tamper`), `grdr-ports` (layer 2 same-layer edge for `grdr_ports::clock::Clock` only, settled by [ADR-0040](ADR-0040-clock-entropy-and-the-retry-executor-adopted-by-rfc-0008.md)), and `std` (`BorrowedFd`, `OwnedFd`, `BorrowedHandle`, `OwnedHandle` only per `ARCH-007`). Zero third-party dependencies, no Cargo features, `#![forbid(unsafe_code)]`, `#![deny(clippy::arithmetic_side_effects)]`, opaque-byte framing only (`ARCH-004`).
   - **`grdr-wire-testkit`** (`layer = 2`, public, `experimental`, `#2062`, `#2063`): holds `MemLink` and `MemNet`, depends on `grdr-wire` only, excluded from `[workspace] default-members` and banned from every layer 4 program's normal closure via `architecture.toml`'s `test-support` list (`#1580`).
   - **`grdr-ipc-os`** (`layer = 3`, `surface = "internal"`, `privilege = "privileged"`, `endpoint` squad, trust core under IPC peer authentication, `#2061`, `#2065`): holds Unix socket (`rustix`, `#419`) and Windows named-pipe (`windows-sys`, `#1750`) implementations of `Link`, `Connector` and `Acceptor`, using `unsafe_code = "deny"`, `#![deny(clippy::arithmetic_side_effects)]`, and `grdr-wire` as its sole workspace dependency. Does not depend on `grdr-os-service` or `grdr-peer-os` (`ARCH-002`); `grdr-daemon` bridges `grdr-os-service` listeners to `grdr-ipc-os` acceptors via `std::os::unix::net::UnixListener` and `impl FnMut() -> io::Result<OwnedHandle> + Send`, keeping `grdr-hook`, `grdr` and `grdr-tray` free of `grdr-os-service`.

2. **Seam tokens, unforgeable proofs, and `ARCH-028` closure (Rules 3 to 4; sections 4 to 7, 12 to 13).**
   - Seam traits `Link`, `Connector`, `Acceptor` and `PeerReader` require private single-call tokens (`&LinkCall`, `&ConnectCall`, `&AcceptCall`, `&ReadCall`) constructible only `pub(crate)` inside `grdr-wire` (`Acceptor::stop` has no token).
   - Proofs (`ClientConn`, `ServerConn`, `PendingPeer`, `Endpoint`, `EndpointIdentity`, `PeerIdentity`, `ProcessHold`) have private fields, `pub(crate)` constructors, and no `Default`, `Clone`, `Deserialize` or `From`. A caller gets a `ClientConn` solely from `peer_auth::open` and a `ServerConn` solely from `peer_auth::accept` -> `PendingPeer::first_frame` (no `PendingPeer::identity()` accessor exists prior to `first_frame`, `m2`).
   - Fault and classification enums (`PathCheck`, `OpenError`, `FirstFrameError`, `Binding`, `PathNode`, `ShapeFault`, `OwnerClass`, `ServerFault`, `Evidence`, `Refusal`) are `#[non_exhaustive]`; `LinkFault`, `ReadFault` and `Accepted` remain exhaustive for `grdr-wire`'s matching. `ServerFault::Principal { seen: OwnerClass }` and `PathNode::{Ancestor(u16), Socket}` keep raw uids, SIDs and paths off `Refusal`.
   - `ARCH-028` (`wire-seams`, `#2066`) closes the remaining `PeerReader`/`Connector` implementation-forgery routes (`G1`, `G3`) across the workspace and `#1593` distribution closures (`architecture.toml` crates `grdr-ipc-os`, `grdr-peer-os`, `grdr-wire-testkit`, workspace test targets, plus embedder links admitted through `dist.toml` `[links]` after passing `check_links`/`check_acceptor`; `PeerReader` is never admitted via `dist.toml`). `ARCH-028` blocks `#377`, `#516`, `#683`, `#684` and `#1745`.

3. **Platform authentication guarantees, bounded waits, and Windows pipe security (Rule 5; sections 6 to 8, 15).**
   - **Endpoint resolution (`peer_auth::resolve`):** One resolver (`P17`), reading `security`-tagged, organisation-scoped rows with decided `grdr_model::InstallProfile` (`Protected` -> `Tamper::Admin`, `User` -> `Tamper::User`; never a pre-choice default per RFC 0009 constraint 2a, and never `Tamper::Platform` in slice 0 per constraint 2e). Protected macOS endpoints sit at `/Library/Application Support/grdr/run/decide.sock` (`#464` / `#2036`); User defaults use the per-user runtime directory (`$XDG_RUNTIME_DIR/<namespace>/` on Linux, `~/Library/Application Support/<namespace>/run/` on macOS).
   - **Unix client & server guarantees:** Client walks every path node from `/` down (`lstat`, zero symlinks, root- or expected-uid-owned directories, `trusted_groups` or caller-owned private group admission, before/after connect identity compare via `PathFacts`) with world-writable socket inode permitted for `connect(2)`, checking listener uid/gid without checking a server executable (`#464` settled). Server uses `SO_PEERCRED` + `SO_PEERPIDFD` / verified `pidfd_open` (`OpenedReading`) on Linux and `LOCAL_PEERTOKEN` on macOS.
   - **Windows client & server guarantees:** Connector opens pipes with `SECURITY_SQOS_PRESENT | SECURITY_IDENTIFICATION` and exact access mask `FILE_READ_DATA | FILE_WRITE_DATA | FILE_READ_ATTRIBUTES | READ_CONTROL | SYNCHRONIZE` (never `GENERIC_WRITE`); service DACL grants those same five rights only with owner set to the service SID and `PIPE_REJECT_REMOTE_CLIENTS` enabled. Client verifies pipe owner SID + two equal SCM `ServiceProcess::Valid(pid)` readings (`ServiceRestarting` Transient on pending/mismatched pid, `M2`), avoiding `OpenProcess` on a service. Server stamps Windows `FileTime` `connected_at` first upon overlapped connect completion (`design/03` §10 `Clock` exception, Rule 5), checks `created <= connected_at`, and requires mandatory `first_frame` `message_identity` (`ImpersonateNamedPipeClient` + `OpenThreadToken(..., TOKEN_QUERY, OpenAsSelf = TRUE)` inside an RAII `RevertToSelf` guard, verifying matching SID and `IntegrityRid`, `m3`).
   - **Bounded waits:** Every seam wait rounds `within` up (never 0) and retries after early `TimedOut` up to `Monotonic` deadlines over `grdr_ports::clock::Clock`, capped at `ipc.call-max` (1,000 ms) and `ipc.first-frame` (1,800 ms) in `limits.toml` (`#279`, `#2064`).

4. **Error codes, evidence classification, privacy, and finding pipeline (Rules 7 to 8; sections 9 to 11, 14, 16).**
   - Registers areas `WIRE` (`GRDR-WIRE-0001..0011`, built in `#374` and `#1606`) and `PEER` (`GRDR-PEER-0001..0011`, built in `#375`) using RFC 0007's standard TOML keys only (`schema/codes/wire.toml` and `schema/codes/peer.toml`, no `evidence` column) and RFC 0010 (`ADR-0044`) unblocked ordering relative to `#1853`.
   - `Refusal::evidence(&self) -> Evidence` is one exhaustive match in `grdr-wire::peer_auth` (tested against `code().class()`): only client-side `Evidence::Tamper` (`PathForeign`, `ServerForeign`) writes deduplicated tamper markers (`#1574`), ingested into tamper findings with privileged audit-log references keeping raw path/uid/SID on the device (`#2067`). `PathUnsafe` raises degraded health `endpoint-unsafe`; `*Unverifiable` and `grdr_daemon_peer_transient_refusals > endpoint.transient-refusal-threshold` (`m4`) raise `peer-unverifiable`; `grdr doctor` formats failing paths under UX6 with account-database redaction for other users' paths (`#707`, `m6`).

5. **Binding acceptance constraints and verification obligations.**
   - **Revision 4 compile-sketch parity constraint (`eval-review` round 4, [`issuecomment-7099936324`](https://github.com/416rehman/Guardrails/issues/1757#issuecomment-7099936324)):** Because the external compile-sketch harness (`#1757` comments `7056002171`, `7056002529`, `7056002830`) verified revision 3 (`533c30d`) and was not re-run standalone on revision 4 (`118f6205`, Unresolved question 5 bullet 6), `#374`, `#1606`, `#375`, and `#555` are bound on acceptance to prove every revision-4 delta in their CI workspace builds, `compile_fail` doctests (`f01` to `f21`, `f17` proving `PendingPeer::identity()` removal, `G2`, `G2b`, `G2c`), exhaustive differential model checks (including arm mismatch `m1` and `Refusal::evidence()` parity), and `OpenAsSelf = TRUE` standard-user Windows test (`m3`).
   - **RFC 0009 constraints (`#1757` comment `7086188492`):** `InstallProfile` and `Tamper` come from `grdr_model` (`#1987`), `Monotonic`/`Clock` from RFC 0008 (`ADR-0040`), `Coded` from RFC 0007 (`#278`), `LogSafe` from RFC 0009 (`#284`); callers pass `resolve` only a decided `InstallProfile` (constraint 2a) and never emit `Tamper::Platform` in slice 0 (constraint 2e).
   - **Refinement of proposed `ADR-0045` (`#2068`):** When [ADR-0045](ADR-0045-daemon-os-calls.md) (`Status: proposed`) is updated or accepted, it adopts RFC 0003 section 15's three refinements (`grdr-ipc-os` for `Link`/`Connector`/`Acceptor`, `grdr-os-service` listener handover without links or client linking, and `PeerReader`/`open`/`accept`/`PendingPeer::first_frame`/`check_path`/`resolve` in `grdr-wire::peer_auth`).
   - **Uninstall verification (`seat 2`, `#2069`):** `#1561` covers hook install-journal replay only; `#2069` tracks closing explicit daemon socket and created service-directory cleanup across `#1283` (Windows MSI), `#1286` (slice 7 `grdr uninstall`), and `#1660` (`$XDG_RUNTIME_DIR` verification beside `#1661` and `#1662`) under `#1650`'s snapshot oracle.
   - **No pin and no evidence:** RFC 0003 edits no pinned file (`docs/design/00-decisions.md` stays at `a80859235e7a2a4444648d6fa8d389d78dde6be9` / `8f6ea876777c0121ecec068c0bc4cef45932be45c1c2aff4140712db1e06628d`). `rfcs/pins.toml` is unchanged and nothing is added under `rfcs/evidence/`.

## Enforced by
- **Type system (`grdr-wire`):** private seam tokens (`LinkCall`, `ConnectCall`, `AcceptCall`, `ReadCall`), private proof fields with `pub(crate)` constructors, split `ClientConn` / `ServerConn`, private-state `PendingPeer`, exhaustive enum states (`OpenedReading`, `ServiceProcess`, `PeerRef`), `compile_fail` doctests `f01` to `f21`, `G2`, `G2b`, `G2c`.
- **Lint and build gates:** `#![forbid(unsafe_code)]` on `grdr-wire` and `grdr-wire-testkit`, `#![deny(clippy::arithmetic_side_effects)]`, `ARCH-002` (no layer 3 <-> layer 3 edges), `ARCH-004` (no content parsers in privileged closures), `ARCH-007` (`cargo public-api` against `surfaces.toml`), `ARCH-017` (`Coded`), `ARCH-025` (amended local/network route lint), `ARCH-027` (`#1751`), `ARCH-028` (`#2066`, closing `G1` and `G3` on workspace and `dist.toml` closures), log-gate scan (`#1989` / `#284`), and `cargo deny check`.

## Consequences
- Slice-0 framing, endpoint resolution, and bidirectional peer authentication proceed under one agreed API and decision table across `core`, `security`, `endpoint`, `adapters`, `server`, `interfaces` and `release`, with zero third-party crates added to `grdr-wire`.
- Raw OS `unsafe` bindings remain strictly confined to layer 3 OS adapter crates (`grdr-ipc-os`, `grdr-peer-os`, `grdr-os-service`), with no dependency edge between layer 3 crates (`ARCH-002`) and no `grdr-os-service` linkage in user-session programs (`grdr-hook`, `grdr`, `grdr-tray`).
- Linux and macOS client authentication cleanly omits unusable server-executable checks under socket activation (`#464` closed), substituting root-owned non-symlink ancestor checks up to `/` and relocating macOS Protected sockets to `/Library/Application Support/grdr/run/decide.sock`.
- Windows standard-user clients verify services without privileged `OpenProcess` calls via pipe-owner + dual SCM pid checks, while servers hold a connect-completion timestamp + mandatory identification-level `first_frame` SID/integrity check (`OpenAsSelf = TRUE`) leaving only a narrow same-SID completion-latency race.
- `ARCH-028` (`#2066`), `grdr-ipc-os` (`#2065`), `grdr-wire-testkit` (`#2062`), `surfaces.toml`/`architecture.toml` (`#2063`), and `limits.toml` bounds (`#2064`/`#279`) gate slice-0 client and server callers cleanly in build order.

## Alternatives rejected
- Recorded in detail in [RFC 0003, Alternatives](../../rfcs/0003-grdr-wire-surface.md#alternatives): forgeable verifier traits (`#374` R4), reader crates making policy decisions, one shared call token across seams (`G2`), client `OpenProcess` on Windows services (`#555` R2), Unix server-executable checks under socket activation (`design/07` L67), local links inside `grdr-os-service` (`F6`), reusing egress `Dialer` for local IPC (`F7`), holding unverified links (`open`/`accept` split), folding `first_frame` into `accept`, failing open on absent `message_identity` (`M1`), treating service restarts as tamper (`M2`), `Option` fields for partial kernel readings (`M3`), `ServerForeign` for server pid-reuse races, async slice-0 APIs before runtime admission, and placing `MemLink`/`MemNet` in `grdr-wire`.
- Pin record or `rfcs/evidence/` files: RFC 0003 modifies no pinned path, so neither is created ([ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).
- Editing reviewed RFC body text for round 4 provenance or constraints: kept lines 11 to 861 byte-identical to reviewed blob `16f0e68e3ef5be431236a161fa9dc9e76dd8f7f5`, updating only `State:`, `Decision record:`, the round-4 verdict links under `## Review`, and `## Decision` ([RFC 0001](../../rfcs/0001-adopt-the-spine.md)).
