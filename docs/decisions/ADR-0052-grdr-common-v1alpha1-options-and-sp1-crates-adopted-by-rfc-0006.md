## Context
Work on `#353` (`04-1`), `#360` (`SP-1`), and `#386` (`04-2`) blocked on four unresolved surface and gate questions under `#17`:
1. `#353` cannot land `proto/**` without an accepted RFC under D-61 (`#17-E1`), and splitting `options.proto` and `data_class.proto` created an import cycle because `options.proto` needed `DataClass` while `data_class.proto` used `(wire_name)` on its enum values.
2. `#360` cannot admit SP-1 codec crates or descriptor decoders into `grdr-proto` and `grdr-schema-lint` without an accepted dependency and feature contract (`#17-E2`).
3. P8 and D-51 require one authoritative source for the five commitment data classes, capture matrix levels, generated `grdr_schema::{capture, registry}` modules, fail-closed base-built `schema-gate` checks (`SL10` to `SL13`, `manifests`, `capture --check`, `registry --check`), and per-organisation `reclassifications.toml` confirmations before deployed devices widen telemetry leaving the endpoint.
4. `buf` v2 rules had to run strictly offline (`WI-0014` rules `W1` to `W5`, `#1697`) against one top-level configuration without per-module overrides, comment ignores, or unstable-package bypasses.

## Decision
**Accepted.** Adopt [RFC 0006](../../rfcs/0006-grdr-common-v1alpha1-options-and-sp1-crates.md) as reviewed at pre-acceptance blob `b14eab1663615bbf8d6cbbebf86b027f6b08536a` (SHA-256 `7ebb59e259facedebb9a8905438f507832a5dcff441fa7126a89b276a2be26c0`, PR `#1865` head `94d3300e687cd28c2983a79117f2c6ddfe87be79`, merged at `06de3cdf278b1afdec63d052399302513966d30c`) and transitioned to `State: Review` at blob `41fcd8a48ad44e2f56d434d4d8d68d70fa4c86c9` (SHA-256 `de9e8607d62ac6f0cedf5d24dde0d826c6544ebbab8de96fe440e986d5f7e022`, PR `#2072` merged at `7f89c77028acf545f61361ccddf4ed84f4e4ebbd`) against pinned spine `docs/design/00-decisions.md` at `a80859235e7a2a4444648d6fa8d389d78dde6be9`:

1. **Unified options package and registry (`R1` to `R8`, `#353`).**
   - `proto/grdr/common/v1alpha1/options.proto` (`syntax = "proto3"`, package `<namespace>.common.v1alpha1` read from `brand/brand.toml [identity] namespace` (`grdr` today, Class A per `design/36` section 2)) declares `DataClass`, `ContentKind`, five descriptor extensions (`50001 data_class`, `50002 content_kind`, `50003 policy_readable`, `50004 sealable` on `FieldOptions`; `50011 wire_name` on `EnumValueOptions`), and no messages, importing solely `google/protobuf/descriptor.proto`.
   - Every tool and reader inspects `<options_package>.<option>` dynamically from each file's import in the committed descriptor set (`R6`), never by hardcoded option numbers or generated extension structs; `#398` moves all five numbers together once a registered global range is granted.

2. **Data classes, `capture.toml`, generated `grdr-schema` modules, and foreign imports (`R9` to `R14a`).**
   - `DataClass` and `ContentKind` are closed enums (`enums.toml` in `#386`) deriving the five commitment class names `structural`, `derived`, `identifier`, `content.argument`, and `content.body` (zero values carry no `wire_name`; `SL13` binds lower-case suffix identity).
   - `crates/grdr-schema/capture.toml` (`R13`, ranked lowest-to-highest sensitivity, `default = "metadata"`, read solely via `grdr-schema-lint`) and `crates/grdr-schema/reclassifications.toml` (`R17`) generate whole-file `crates/grdr-schema/src/capture.rs`, `crates/grdr-schema/registry/fields.json`, and `crates/grdr-schema/src/registry.rs` (`R13a`, declared as plain `pub mod capture;` and `pub mod registry;` in `crates/grdr-schema/src/lib.rs`). All shipped Rust readers (`#117`, `#511`, `#2096`, `#2099`, `04-21`, disclosure UI/tray, configuration defaults) consume only those generated modules.
   - `SL10` permits non-namespace imports strictly via SHA-256 descriptor digest matching against `crates/grdr-schema-lint/foreign_files.toml` (`google/protobuf/descriptor.proto`, `timestamp.proto`, `duration.proto`); imported leaves inherit their holding field's class in the registry (`R14a`).
   - Message-typed `encoding`, digest `<alg>` labels, nested message-field comparison semantics in `SL12`, principal markers, `EvidenceSpan`/content-grant routes, and partner packages are deferred explicitly to `#18`'s RFC (`R14`).

3. **Stability class authority and `reclassifications.toml` / R17b device hold (`R15` to `R17c`).**
   - `surfaces.toml` is the sole authority for package stability (`#2094`: `[[proto_package]]` `package = "common.v1alpha1"`, `class = "experimental"`; `SL11` rejects `stable` rows with unstable version suffixes).
   - Any field treatment change or removal (`[[field]]` with treatment `"<class> [sealable]"` and mandatory `successor` on `"removed"`), capture level opening (`[[level]]`), or wire-name change/removal (`[[wire_name]]`) requires an append-only entry citing the PR's `RFC:` in `Accepted` state (resolved by `#1741`'s checker) and seat 6 (`persona-privacy-officer`) or seat 3 (`persona-soc-analyst`) `review` comment checked by `#1880`'s four-point evaluator rubric (`R17`, `R17a`).
   - Deployed endpoints apply the least-open unconfirmed treatment (`R17b`, holding `sealable` loss too) until the organisation records a signed D-31 confirmation for that specific entry (`#1878`, `#117`), accompanied by `R17c` `security`/`breaking` release notes and UI pending diffs.

4. **Offline `buf` gate, trust-core paths, and fresh-copy fixtures (`R18` to `R23`).**
   - Root `buf.yaml` (`#2093`) configures `version: v2` with top-level `lint` (`use: [STANDARD]`, `disallow_comment_ignores: true`), top-level `breaking` (`use: [WIRE_JSON]`), and one minimal `{ path: proto }` entry verified offline (`W1` to `W5`) against four fresh-copy fixture directories under `schema/fixtures/buf/` (`renumbered_field`, `reused_enum_value`, `comment_ignore`, `stale_descriptor`).
   - R19 registers 18 trust-core path lines ignoring ASCII case (`**/build.rs` already landed via `#1955`/`#2047`; `#2093` lands the remaining 17 lines), plus `<dir>/**` for any workspace `proc-macro` package and `depends_on = []` on `[crates.grdr-schema-lint]` in `architecture.toml`.
   - `crates/grdr-proto/descriptors/proto.binpb` keeps imports (`--exclude-imports` forbidden) and is regenerated in the same PR on every `proto/` change (`#1842`).

5. **SP-1 trial codecs and lint decoder (`R24` to `R31`, `#360`).**
   - `grdr-proto` admits `buffa`, `buffa-types`, `buffa-build` `0.9.2` under optional feature `sp1-buffa`, and `prost`, `prost-types`, `prost-build` `0.14.6` under optional feature `sp1-prost`, enforced mutually exclusive with `compile_error!` (`hashbrown` held at `0.17.1` per cooldown rule R30; build scripts compile committed descriptors only with `PROTOC` unset and neither `protoc` nor `buf` on `PATH`).
   - `grdr-schema-lint` decodes committed descriptor sets via `buffa-descriptor` `0.9.2` (`reflect`) regardless of SP-1's outcome, until an amending RFC moves it (`R26`). `#360` records the 63-crate closure (`47` if `#1575`'s `16` shared rows are already locked) in `supply-chain/admissions.toml` using the new `feature` consumer key (`R31`).

6. **`grdr-schema-lint` commands, `manifests`, and hardened `schema-gate` (`sections 7 to 8`).**
   - `#2095` implements `SL10` to `SL13`, strict TOML loaders, `capture`, `registry`, `compare`, `manifests`, `buf` JSON comparison (`proto` job development check, `L-4`/`H-2`), an independent `compare` table model with differential testing (`D-63`), and section 8 seeded fixtures.
   - `manifests` (`#2095`) and `schema-gate` (`#1843`) enforce fail-closed reading: checking `refs/replace/` (`GRDR-GATE-0007`, `exit 2`), running `.github/actions/tree-paths/check_tree.py --rev <head_id>` before extracting verified regular-file git blobs by object id (no `git archive`), running `cargo metadata --no-deps --offline` outside the head tree with base-pinned `RUSTUP_TOOLCHAIN`, reading head bounds from base `limits.toml` (`G-1`), failing on any `exit 1` or `exit 2` (`manifests::decoy_crate_path` `exit 1` vs `manifests::missing_or_unreadable` `exit 2`), and failing closed on push-to-`main` mismatches.

7. **Binding acceptance constraints (`#1848` Round 5/6/8 & cross-RFC coordination).**
   - Constraints `G-1` (`#2093`), `L-1` to `L-8` (`#2095`), `K-1` (`#117`), `H-1` to `H-2` (`#1843`), `B-1` (`#1856`), `C-1` (`#1878`), `E-1` to `E-3` (`#1880`), `F-1` (`#1741`), `P-1` (`#493`), and `Q-1` (`#18`) bind all implementing items.
   - Because `ADR-0043` excludes `Cargo.lock`, root `Cargo.toml`, and `supply-chain/admissions.toml` from `security/trust-core.paths`, `#2097` (`Cargo.lock == supply-chain/admissions.toml` + `verify.yml` `rust` job `protoc`/`buf` isolation) and `#1910` (post-cargo `git status --porcelain` clean-tree check across all CI Cargo and release jobs) are required protections before relying on release builds (`cargo-deny` and `osv-scanner` guard third-party crates during the interim).
   - `crates/grdr-schema/tests/construction.rs` (`layout`, established under RFC 0007 `#278`/`#279` and modularised across `{codes, limits, health}` triplets by [ADR-0050](ADR-0050-health-condition-registry-adopted-by-rfc-0016.md) `#2056`): `#2095` updates `tests/construction.rs` `layout` cleanly if `#278` or `#2056` lands first so `src/capture.rs`, `src/registry.rs`, and `L-1` `src/registry/*.rs` coexist with `{codes, limits, health}` triplets while preserving plain `pub mod` declarations for `#1880` `E-1`.

8. **No pin, no evidence, no index file edit.**
   - RFC 0006 changes no pinned path in [`rfcs/pins.toml`](../../rfcs/pins.toml) (`docs/design/00-decisions.md` remains `a80859235e7a2a4444648d6fa8d389d78dde6be9`), adds no file under `rfcs/evidence/`, and leaves `docs/decisions/README.md` and `rfcs/README.md` uncreated ([ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).

## Enforced by
- **Proto build and `buf` checks (`#2093`, `#353`, `#1842`):** root `buf.yaml` (`STANDARD`, `disallow_comment_ignores: true`, `WIRE_JSON`, zero bypass keys), pinned `[tool.buf]` offline runs, and four negative-control fixtures run on fresh checkouts with `proto` input.
- **Base-built `grdr-schema-lint` and `schema-gate` (`#2095`, `#1843`, `#1879`):** `#![forbid(unsafe_code)]`, pre-cargo `check_tree.py` (printable ASCII, case-fold collisions, zero symlinks/submodules), `GRDR-GATE-0007` refusal on `refs/replace/`, verified git blob extraction, out-of-tree `cargo metadata`, `SL10` to `SL13`, byte-exact `capture --check` and `registry --check`, fail-closed `exit 1`/`exit 2` handling, independent `compare` differential tests, and required ruleset checks (`#1879`).
- **Workspace build & lockfile supply-chain checks (`#360`, `#2097`, `#1910`):** `compile_error!` mutual exclusion of `sp1-buffa`/`sp1-prost`, `wasm32-unknown-unknown` builds per feature, `PROTOC`/`protoc`/`buf` isolation in `verify.yml` `rust`, `Cargo.lock == supply-chain/admissions.toml` check, `#1910` post-cargo clean-tree check, `cargo-deny`, and `osv-scanner`.
- **Two-model evaluator lane and rubric (`#1880`):** trust-core review via `eval-review` + `eval-security` on two distinct models/providers (`D-63`, `ADR-0043`), plus `#1880`'s four per-entry checks and plain `pub mod` inspection on `lib.rs`.

## Consequences
- `#353`, `#360`, `#386`, `#1842`, `#1843`, and `#117` have one settled protobuf option schema, offline gate architecture, SP-1 trial dependency plan, and sequential execution graph gated on `#1848` merge.
- No generated file, `capture.toml` class rank, or deployed endpoint default can silently drop a field classification, weaken capture filtering, bypass `reclassifications.toml`, or redirect `grdr-schema`/`grdr-model` manifests via build scripts.
- Keeping third-party `Cargo.lock` closures outside `security/trust-core.paths` under [ADR-0043](ADR-0043-lean-token-optimised-agent-team.md) avoids blocking routine dependency hygiene while making `#2097` and `#1910` explicit preconditions before release builds depend on `Cargo.lock` build scripts or proc macros.
- `rfcs/0006` introduces temporary dual SP-1 feature flags (`sp1-buffa`, `sp1-prost`) and locks 63 packages (`47` beyond `#1575`'s `16`) until `#368`'s decision record adopts the winning codec and removes the loser.

## Alternatives rejected
- Recorded in [RFC 0006, Alternatives](../../rfcs/0006-grdr-common-v1alpha1-options-and-sp1-crates.md#alternatives): separate mutually cyclic `options.proto` and `data_class.proto` files, hardcoded options-package or option-number literals, per-field/per-file `stability` options outside `surfaces.toml`, premature `encoding` options before `#18`, reading reclassification decisions from RFC Markdown prose, head-built `SL12`/drift checks, `git archive` materialisation of head trees, `--bootstrap` exceptions, RFC-level rather than per-entry organisation confirmations, enabling `sp1-buffa` and `sp1-prost` together, and admitting `prost-reflect` (`0.16.5`) or `protobuf` (`4.x` pre-release) before SP-1 completes.
- Modifying `rfcs/pins.toml` or writing `rfcs/evidence/`: RFC 0006 edits no pinned path ([ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).
- Editing reviewed RFC 0006 body text during acceptance: lines 11 to 558 remain byte-identical to reviewed blob `b14eab1663615bbf8d6cbbebf86b027f6b08536a` and `State: Review` blob `41fcd8a48ad44e2f56d434d4d8d68d70fa4c86c9`, updating solely `State:`, `Decision record:`, review provenance links, and `## Decision` ([RFC 0001](../../rfcs/0001-adopt-the-spine.md)).

## Revisit when
- `#353` AC-1 discovers the pinned `buf` (`#1697`) rejects self-referential `(wire_name)` usage inside `options.proto`, requiring an amending RFC (`R1`).
- `#368` selects `prost` over `buffa`, opening an amendment RFC to consider migrating `grdr-schema-lint` from `buffa-descriptor` to `prost-reflect` and removing `sp1-buffa` (`R26`).
- `#18` arrives to define `encoding`, digest labels, message-typed field rules in `SL12`, human-principal markers, `EvidenceSpan`/content-grant routes, and partner packages (`R14`).
- `04-29` freezes `grdr.common.v1alpha1` into `v1` and switches `buf breaking` from `WIRE_JSON` to `FILE`, requiring an amending RFC on `R6`, `SL10`, and `v1alpha1`->`v1` predecessor tracking (`R17a`).
