## Context
Under D-69 and WI-0041 (`#29`), every user-facing and agent-facing string comes from MessageFormat 2 (MF2) language tokens rather than hard-coded Rust or TypeScript literals (`P14`, `P17`), backed by ICU4X 2.4 (`docs/design/28` section 13, `docs/design/34` section 15a). Because `grdr-strings` is a new layer 2 `public` crate and introduces the ICU4X 2.4 / `zoneinfo64` dependency closure into `Cargo.lock`, D-61 and D-63 require an accepted RFC before `#449`, `#1612`, `#1613`, `#1614`, `#1615`, `#1616`, `#1618`, `#1384`, and `#1853` can proceed.

Before RFC 0017:
- Following [`docs/design/28`](../design/28-desktop-and-developer-experience.md) section 13 ("ICU4X 2.4 with baked data for the shipped locales") naively with `icu_provider_baked` code generation emits `unsafe { VarZeroSlice::from_bytes_unchecked(...) }` and direct `icu_provider` / `zerovec` imports inside `grdr-messages`, violating workspace `[workspace.lints.rust] unsafe_code = "forbid"` and `ARCH-024` (`strings-closure`).
- `grdr-strings` (layer 2) must perform zero I/O and read no clock (`ARCH-003`), yet `design/34` section 15a requires rendering `grdr_model::Timestamp` (`0001-01-01..=9999-12-31`, RFC 0009) in any viewer's time zone without overflowing `icu_calendar` epoch bounds, and computing `:grdr:relative` only from caller-supplied `reference_now`.
- `P8` requires compile-time and runtime guarantees that `Content`-class arguments never reach `notify.*`, `email.*`, or pack notification templates, never leak into `LogSafe` logs or `Debug` output, and never cross bidi/terminal escape boundaries (`U+202A..=202E`, `U+2066..=2069`, ANSI/C0/C1 controls).
- Downstream item `#1886` (referenced in RFC 0017 section 1 `R1.1` for a JSON Schema 2020-12 validator crate) closed after RFC 0017 was drafted under its Option B fallback (generated typed `serde` envelope with `#[serde(deny_unknown_fields)]` and structural `serde_json` schema checks, admitting zero extra crates); `#1613` can apply that same zero-dependency mechanism without altering RFC 0017's surface.

## Decision
**Accepted.** The language-token runtime contract across `grdr-strings`, `grdr-messages`, and `grdr-interface-gen` and the ICU4X 2.4 dependency closure are RFC 0017 at pre-acceptance reviewed blob `cabe7ab126651fbe22e55caf1be00cda4caa0fac` (SHA-256 `46aad6f39956eec65f1fb124c6699b316d609b909eef656d8540a45dd332d47f`), written against spine pin `a80859235e7a2a4444648d6fa8d389d78dde6be9` (SHA-256 `8f6ea876777c0121ecec068c0bc4cef45932be45c1c2aff4140712db1e06628d`) ([RFC 0017, Design](../../rfcs/0017-grdr-strings-language-token-runtime.md#design)). In outline:

1. **Crate placement, purity, bounds, and `grdr-strings` public surface (`R1`).**
   - `grdr-strings` is layer 2, `surface = "public"` (`experimental` in [`surfaces.toml`](../../surfaces.toml), `#2087`), `privilege = "none"`, `renders = "none"`, `#![forbid(unsafe_code)]`, `#![deny(clippy::arithmetic_side_effects)]`, `wasm32-unknown-unknown`-compatible, with zero filesystem/network/env/clock/entropy I/O (`ARCH-003`). It depends only on `grdr-schema` (layer 0), `grdr-model` (layer 1), and Section 5's pinned third-party crates, exporting all normative public items at the crate root (`grdr_strings::*`).
   - Exposes `DataClass`, `MessageDomain`, `ArgType`, `ArgDecl`, `MessageId`, `DecimalInput` (exact base-10 decimal preventing binary float drift), `BrandSlot`, `ArgValue`, `NamedArg`, `MessageArgs`, `MessageRef` (carrying `[u8; 32]` `source_hash`), `#[non_exhaustive]` `StringError`, `#[non_exhaustive]` `Mf2Function` (closed 9-function registry: `:number`, `:integer`, `:datetime`, `:unit`, `:grdr:relative`, `:grdr:duration`, `:grdr:list`, `:grdr:brand`, `:grdr:term`), `MessageTemplate`, `CompiledPackMessage` (`pack-text`), `LocaleTag`, `LocaleTier`, `Direction`, `LocaleEntry`, `ScriptTag`, `BidiIsolation`, `ViewerTimeZone`, `LocaleBundle`, `BrandContext`, `TermTable`, `FormatContext`, `PseudoLocale` (`en-XA`, `ar-XB`, `ja-XC`), and free functions `format_template`, `format_utc_iso8601`, `negotiate_locale`, `resolve_output_locale`, `normalise_nfc`, and `format_pseudo_template`.
   - Every parser, AST, `.local` depth, `.match` branch, pack-blob, list-item, pseudo-expansion, and agent-block bound reads `grdr_schema::limits` constants generated from eight `[bound.strings.*]` rows in `limits.toml` (`#2086`, `ARCH-019`, `GRDR-STR-0012`).
   - `:datetime` shifts `grdr_model::Timestamp` (`MIN..=MAX`) via in-memory `zoneinfo64` over aligned `[u32; N]` words and constructs shifted dates with `icu_calendar::Date::try_from_fields` plus Gregorian fallback at extreme epoch boundaries so formatting never fails or panics; `:grdr:relative` on `Timestamp` requires explicit `reference_now: Some(Timestamp)` (`GRDR-STR-0005`).
   - Rejects forbidden Unicode bidi and C0/C1/ANSI escape controls (`GRDR-STR-0010`), isolates `Identifier` placeholders in `LRI`/`PDI` with `latn` ASCII digits, wraps all other dynamic placeholders in `FSI`/`PDI` in every locale (`Isolate`), and routes RTL + `BidiIsolation::Strip` to `"en"` (refusing unisolated RTL emission via `GRDR-STR-0011`).

2. **`grdr-messages` contract and static Postcard / `[u32; N]` layout (`R2`).**
   - `grdr-messages` is layer 2, `surface = "unpublished"`, `privilege = "none"`, `renders = "generated"`, depending solely on `grdr-strings` (listed same-layer edge in [`architecture.toml`](../../architecture.toml)), plus `grdr-interface-gen` and `trybuild` as dev-dependencies only.
   - `grdr-interface-gen generate` deterministically writes `crates/grdr-messages/src/generated/` (`cldr_shipped.postcard`, `zoneinfo64_u32.rs`, `tokens.rs`, `present.rs`, `ids.rs`, `catalogue.rs`, LF endings) from committed offline master snapshot `interface/strings/cldr/{cldr49-data.postcard,zoneinfo64.res,manifest.toml}` (CLDR `49.0.0`, Unicode `18.0.0`, TZDB `2026e`), verified by `cargo test -p grdr-messages drift` (`GRDR-MSG-0002`) with no build-script invocation.
   - Replaces `icu_provider_baked` Rust codegen (which emits `unsafe` `VarZeroSlice::from_bytes_unchecked` and leaks `icu*` imports into `grdr-messages`) with `BlobDataProvider::try_new_from_static_blob` and `ZoneInfo64::try_from_u32s` inside `grdr-strings`, preserving `#![forbid(unsafe_code)]`, `ARCH-024`, zero runtime I/O, and compile-time `cargo check` rejection of missing tokens, missing arguments, and wrong argument types.
   - `MessageError` implements `Coded` and `LogSafe`, delegating `BundleInit` and `Format` verbatim to `StringError::code()` (`ARCH-017`) while mapping `UnknownMessageId` to `GRDR-MSG-0001` and `DriftDetected` to `GRDR-MSG-0002`.

3. **Features `pack-text` and `export` and `ARCH-024` `strings-closure` (`R3`).**
   - Only `grdr-strings` declares `icu*` or `zoneinfo64` dependencies. `default = []`.
   - `pack-text` gates `CompiledPackMessage` and `LocaleBundle::from_boxed_blobs`, and is allowed solely in `grdr-engine`, `grdr-server`, and `grdr` (`ARCH-024` per-manifest feature resolution); it is forbidden in `privileged` programs (`grdr-daemon`, `grdr-updater`, `grdr-approve`) and in `grdr-wasm`/`grdr-ffi` (`ARCH-004`, `ARCH-024`).
   - `export` (`dep:icu_provider_export`, `icu_provider_blob/export`) is allowed solely in `grdr-interface-gen` and `grdr-strings` dev/unit tests, never in layer 3/4/`privileged`/`wasm32`. `grdr-hook` links neither `grdr-strings` nor `grdr-messages`.

4. **Admitted ICU4X 2.4 crates and supply-chain discipline (`R4`).**
   - Admits exact-pinned `2.4.0` crates (`icu_provider`, `icu_provider_adapters`, `icu_provider_blob`, `icu_locale_core`, `icu_locale`, `icu_locale_fallback`, `icu_collections`, `icu_properties`, `icu_normalizer`, `icu_decimal`, `icu_plurals`, `icu_list`, `icu_calendar`, `icu_time`, `icu_datetime`, `icu_segmenter`, plus tool-only `icu_provider_export`), `icu_experimental = "=0.7.0"`, `fixed_decimal = "=0.7.3"`, `writeable = "=0.6.4"`, `zoneinfo64 = "=0.3.0"`, and `postcard = "=1.1.3"` (`Unicode-3.0` or `MIT OR Apache-2.0`, both permissive in [`supply-chain/licences.toml`](../../supply-chain/licences.toml)), with `compiled_data` excluded from runtime binaries and full `wasm32-unknown-unknown` support.
   - `#449` records the complete resolved `Cargo.lock` closure, SHA-256 checksums, build-script / proc-macro audit, and 3-day / 7-day publish-cooldown checks ([`docs/design/35`](../design/35-product-security-programme.md) section 2.6) in [`supply-chain/admissions.toml`](../../supply-chain/admissions.toml) before merging, and verifies `icu_experimental` `0.7.0` does not pull `icu_experimental_data` unconditionally.

5. **`grdr:class` taint, privacy (`P8`), and error codes (`R5`, RFC 0007, RFC 0010).**
   - `MessageTemplate::parse` and `CompiledPackMessage::from_compiled_bytes` re-validate AST/size bounds, closed functions, non-nested `*`-terminated `.match` nodes, `.local` `DataClass` upward taint propagation (`:grdr:brand` / `:grdr:term` fixed at `Structural`), downgrade refusals (`GRDR-STR-0007`), URL/markup/control absence on pack blobs, and fail-closed `Content` default on unclassified standalone dynamic variables (`parse_infer`).
   - `notify.*`, `email.*`, and pack notification templates carrying any `Content`-class argument fail `grdr-interface-gen check` (`GRDR-IFG-0008`), fail `from_compiled_bytes` (`GRDR-STR-0007`), fail at format time (`DisallowedDataClass`), and lack `Content`-accepting parameters in `grdr-messages`. `MessageRef`, `ArgValue`, `NamedArg`, and `MessageArgs` implement redacting `Debug` and never implement `LogSafe`.
   - Registers experimental areas `STR` (`GRDR-STR-0001..0012`), `MSG` (`GRDR-MSG-0001..0002`), and `IFG` (`GRDR-IFG-0001..0009`) in `schema/codes/` (`#2088`) under RFC 0007 (`ADR-0038`) and RFC 0010 (`ADR-0044`, unblocked before `#1853` R2 lands).

6. **No pin and no evidence.**
   - RFC 0017 decides no pinned path. [`rfcs/pins.toml`](../../rfcs/pins.toml) stays unchanged at `docs/design/00-decisions.md` blob `a80859235e7a2a4444648d6fa8d389d78dde6be9` (`sha256` `8f6ea876777c0121ecec068c0bc4cef45932be45c1c2aff4140712db1e06628d`), and no file is added under `rfcs/evidence/` ([RFC 0001](../../rfcs/0001-adopt-the-spine.md#design); [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).

7. **What this acceptance binds.**
   - Adding, removing, or changing any public item, variant, signature, MF2 function, `DataClass` taint/downgrade rule, bidi/control invariant, or `pack-text`/`export` closure boundary in `grdr-strings` or `grdr-messages`, admitting extra `icu*` dependencies, or promoting `grdr-strings` out of `experimental` requires an amending RFC naming RFC 0017.
   - Authoring tokens under `interface/strings/`, promoting a locale from `preview` to `shipped`, or adding `IFG` codes under RFC 0007 section 4 remains content/additive registration without amending RFC 0017.

## Consequences
- `#449`, `#1612`, `#1613`, `#1614`, `#1615`, `#1616`, `#1618`, `#1384`, and `#1853` unblock onto one decided Rust API, generated crate layout, data-class taint model, error-code schema (`STR`/`MSG`/`IFG`), and ICU4X 2.4 / `zoneinfo64` dependency closure.
- Static Postcard + aligned `[u32; N]` blob delivery avoids `icu_provider_baked`'s `unsafe` codegen and keeps `icu*` dependencies completely out of `grdr-messages` and privileged binaries (`#2089`).
- `Content`-class placeholders cannot reach `notify.*`, `email.*`, pack notifications, or unisolated/unescaped terminal outputs either statically (`grdr-interface-gen`, Rust types) or dynamically (`MessageTemplate` / `CompiledPackMessage` domain checks and `.local` taint tracking).
- `grdr-interface-gen` consumes structural `serde_json` / typed `serde(deny_unknown_fields)` validation (`#1886` Option B) rather than an external JSON Schema validator crate.

## Alternatives rejected
- Those of [RFC 0017, Alternatives](../../rfcs/0017-grdr-strings-language-token-runtime.md#alternatives): generating `icu_provider_baked` modules inside `grdr-messages`, admitting `jiff` instead of `zoneinfo64`, decoupling `grdr-strings` from `grdr-schema`/`grdr-model`, admitting `unicode-segmentation`/`unicode-bidi` beside ICU4X, defaulting omitted `grdr:class` in standalone strings to `Structural`, and enabling `compiled_data` in runtime builds.
- Adding a pin record or `rfcs/evidence/` files: RFC 0017 changes no pinned path ([RFC 0001](../../rfcs/0001-adopt-the-spine.md#design); [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).
- Editing RFC 0017's reviewed `Summary`, `Motivation`, `Design`, `Surfaces changed`, `Alternatives`, `Drawbacks`, `Unresolved questions`, or pre-verdict `Review` text on acceptance: RFC 0001 ("Review binds the decision") permits changing only `State:`, `Decision record:`, verdict link lines under `## Review`, and `## Decision`.
