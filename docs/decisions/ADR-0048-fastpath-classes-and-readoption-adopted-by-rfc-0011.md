## Decision
**Accepted.** RFC 0011 (amendment 1 of RFC 0005) is accepted on reviewed RFC file blob `16232345ebb55263cd4adfc0ddb358905b994407` (accepted file blob `f2a145e7127baabec37f58e0a234d190237cf4d5`) against spine pin `a80859235e7a2a4444648d6fa8d389d78dde6be9` ([RFC 0011, Design](../../rfcs/0011-fastpath-amendment-1-classes-and-readoption.md#design)). In outline:
- **R1 (`FASTPATH` classes and state-code `fatal` semantics).** `Arg(Path)` and `Arg(Destination)` take `class = "input"` (`invalid_argument`); `State` stays `retryable`; entering floor-missing on `Changed`, `PreBackground2b` repeat `Changed`, and `[retry.fastpath-reload]` give-up all take `retryable`; `1d` bound elapsing and a fifth `FASTPATH` state code (`2b` cycle ended) take `fatal`, meaning automatic recovery has stopped and external exits named in `fix` apply (never terminal); `2a` cooldown refusal takes `retryable` (`unavailable`), and rate-bound, `Serving`, and enrolled `local` / wrong peer / SR-04 refusals take `policy` (`resource_exhausted`, `failed_precondition`, `permission_denied`).
- **R2 (`1d` endpoints and named exits from `No tables since start`).** Before first adoption and past the `1d` bound, `decide`, `provider` decision serving and agent hooks (`1c`) stay down (already-registered hooks answer via the D-14 fail-safe table only), while `local` starts and stays up for `Status`, `Explain`, `Query`, `Subscribe` and standalone `2a`, and `grdr-uplink` runs on enrolled devices, preserving `1a` container-only denial (`degraded_reason = floor-missing`). Exits from `No tables since start` are bundle activation or `#1538` recompile on new facts, authenticated `2a` when the verified source compiles and loads, replacing or repairing a solo device's local bundle at or above the D-37 generation floor (never lowering or clearing the floor automatically), or host/daemon restart.
- **R3 (`2b` scope and `ProbationStage`).** `2b` follows both `PreBackground2b` repeat `Changed` and `[retry.fastpath-reload]` giving up identically. R2.19's `Floor-missing, reloading ended` splits into `Floor-missing, background cooldown`, `Floor-missing, background pending` and `Floor-missing, auto-recovery ended`, `Serving, on probation` carries `ProbationStage { PreBackground2b, PostRecovery2b }`, all adoptions from `2b` or post-recovery states enter `PostRecovery2b` (moving directly to `auto-recovery ended` on repeat `Changed` without re-arming `2b`), only `fastpath.reload-settle` elapsing closes the episode and refills both retry policies, and `loss_closed_classes` remains a variant field across all `Serving` and `Floor-missing` states.
- **R4 (`2a` D-55 roles, route, SR-04, bounds and refusal audit).** Replaces `"operator"` with D-55 `Responder` (`Re`) and active delegated `Provider response technician` (`TR`) acting via signed server [`CommandEnvelope`](../design/22-transport-fleet-and-updates.md) (`response.execute`, `audit.admin`), closing the `local` `2a` route on enrolled devices. Standalone keeps one unelevated `local` `ReAdopt` command (`#1930`, `#1883`) authenticated by kernel peer handle (`SR-01`) as a non-widening operational trigger under SR-04 while refusing agent-session lineage unconditionally (CLI exit `4`). `2a` is accepted only in non-cooldown missing-floor states (`Serving` refused `failed_precondition`; `2b` cooldown refused non-silently `retryable`/`unavailable`), bounded across all eligible states by `([bound.fastpath.readopt-max], [bound.fastpath.readopt-window])` in `(Count, Ms)` in `limits.toml` spent only by accepted requests, with refused requests audited per peer and window in aggregate without bundle content.

**No pin and no evidence.** RFC 0011 decides no pinned path of `rfcs/pins.toml`, so its `Decision` section holds no decision line, `rfcs/pins.toml` is unchanged, nothing is added under `rfcs/evidence/`, and `rfcs/0005-fastpath-rust-surface.md` (`4ad52380450ff611f274b4813a19a7f8e412eb7f`) is not edited ([RFC 0001, "RFC states"](../../rfcs/0001-adopt-the-spine.md#design); [ADR-0036](ADR-0036-the-amended-spine-is-the-baseline-adopted-by-rfc-0001.md)).

**Constraints (R5 write-backs).** Alongside [ADR-0037](ADR-0037-the-fast-path-rust-surface-adopted-by-rfc-0005.md), this decision binds:
1. **`#427` (`grdr-daemon` engine supervision):** register the amended `4d` `FASTPATH` classes (`Arg(Path)` / `Arg(Destination)` as `input`, initial floor-missing / repeat / give-up as `retryable`, `Changed` / `1d` / fifth `2b` auto-recovery-ended state code as `fatal`), keep `local` up and `decide`/`provider`/hooks down before first adoption and past `1d` with `1a` container-only denial, implement `ProbationStage { PreBackground2b, PostRecovery2b }` and the 30-row R3.2 transition matrix, refuse `2a` while `Serving`, and add the R5 `fastpath_reload` test cases.
2. **`#1930` (`2a` command and daemon handler):** implement D-55 `Re` / `TR` `CommandEnvelope` delivery on enrolled devices with enrolled `local` `2a` closed (`policy`, `permission_denied`, exit `4`), standalone `local` `ReAdopt` (`SR-01` peer uid match, non-widening under SR-04, session lineage refused exit `4`), R4.5 evaluation order with accepted-only `(Count, Ms)` rate spend, explicit cooldown (`retryable`/`unavailable`) and `Serving` (`failed_precondition`) refusals, per-peer aggregated refusal audits without bundle content, and the R5 negative tests.
3. **`#1917` (`limits.toml` fast-path rows):** define `[bound.fastpath.readopt-max]` (`count`) and `[bound.fastpath.readopt-window]` (`ms`) (`scope = "fixed"`, `effect = "none"`, `owner = "design/26"`) across all eligible states, and align `[retry.fastpath-reload-background]` and its `ms` cooldown with R3 and R4.5 cooldown refusals.
4. **`#1925`, `#278`, `#1921`, `#1538`, `#1916`, `#149`:** update `#1925` and `#278` for the five daemon state codes (`fatal` external-exit `fix` guidance including solo bundle repair/replacement at or above the D-37 floor) and the `2a` refusal codes; update `#1921` `SR-new-W` and `SR-new-X`; keep `local` and `grdr-uplink` running across failed `1b` startup checks and enforce the D-37 generation floor on solo bundle repair/replacement in `#1538` and `#149`; and align [`docs/design/11`](../design/11-endpoint-engineering.md), [`docs/design/18`](../design/18-response-approvals-and-soc-operations.md), [`docs/design/22`](../design/22-transport-fleet-and-updates.md) and [`docs/design/26`](../design/26-embedding-oem-and-white-label.md) in `#1916`.

**What this acceptance binds.** RFC 0005 section 2a, R2.19 and Decision constraints `1d`, `2a`, `2b`, `3` and `4d` stand as amended by RFC 0011 and change only by a later RFC naming both RFC 0005 and RFC 0011 ([`docs/design/30`](../design/30-open-source-governance-and-community.md) section 3). `#427`, `#1930` and `#1917` unblock from `#1940` once `#1940`'s decision pull request merges to `main` and write-backs are posted on the affected issues.

## Enforced by
- **Code registrations and tokens (`#278`, `#427`, `#1930`, `#1925`):** `schema/codes/fastpath.toml` registration check (`grdr-schema`) freezes `class` (`input`, `retryable`, `fatal`, `policy`, `internal`) and `connect` codes; `grdr-interface-gen` (`#1853`) and `/codes` pages (`#1636`, `#1925`) hold `message`/`fix` tokens naming external recovery exits and solo D-37 bundle repair.
- **State-machine and endpoint behaviour (`#427`, `#1538`, `#149`):** typed `ProbationStage { PreBackground2b, PostRecovery2b }` and explicit `Floor-missing` variants (`S4`) verified by `fastpath_reload` unit/simulation tests (give-up to `2b`, `Activation`/`#1538`/`2a` to `PostRecovery2b`, repeat `Changed` straight to `auto-recovery ended`, `Serving` refusing `2a`, `1d` keeping `local` up and `decide`/hooks down, and D-37 floor never lowered automatically).
- **`2a` authorisation, bounds and anti-amplification (`#1930`, `#1917`):** `limits.toml` validation (`ARCH-019`, RFC 0007 sections 5 and 6) over `[bound.fastpath.readopt-max]` (`count`) and `[bound.fastpath.readopt-window]` (`ms`), plus `#1930` negative tests for enrolled `local` refusal, `Re`/`TR` vs `Op` `CommandEnvelope` verification, `Serving` timer invariance, non-silent cooldown refusal, agent-lineage / wrong-uid refusal, unspent rate budget on refusals, and per-peer aggregated audit without `content` fields (`WI-0014`, `LogSafe`).
- **Design and threat-model alignment (`#1916`, `#1921`):** evaluator review on `#1916` and `#1921` confirms `docs/design/02`, `11`, `18`, `22` and `26` match R1 to R5.

## Consequences
- Unblocks `#427`, `#1930` and `#1917` from `#1940` once `#1940`'s decision pull request merges to `main`, with unambiguous `FASTPATH` classes, `limits.toml` units (`count`, `ms`), D-55 `Re`/`TR` routing, and complete 30-row R3.2 floor transitions.
- Enrolled devices no longer expose a local `2a` recovery or rate-exhaustion bypass, while standalone devices keep one unelevated `local` `ReAdopt` trigger and solo devices with corrupted/down-level bundles have an explicit D-37-preserving recovery path.
- Adds one `fatal` `FASTPATH` state code (`2b` auto-recovery ended) and explicit `2a` refusal codes (`cooldown`, `rate limit`, `already serving`, `enrolled local closed`) to `#427`, `#1930` and `#1925`.
- [`rfcs/0005-fastpath-rust-surface.md`](../../rfcs/0005-fastpath-rust-surface.md) stays unedited on `main`; readers read RFC 0011 and this record alongside RFC 0005 and [ADR-0037](ADR-0037-the-fast-path-rust-surface-adopted-by-rfc-0005.md).
