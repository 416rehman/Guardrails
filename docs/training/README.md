# Guardrails ADR Training Labs

Hands-on self-paced labs designed for onboarding solo developers, SRE operators, and external extenders.

- [Developer Lab](developer-lab.md): Build workspace binaries, verify `grdr-hook` fail-closed behavior, run `grdr mcp-proxy`, and verify hash-chained audit logs.
- [Operator Lab](operator-lab.md): Run split Console/Operator servers, execute `grdr server preflight --profile embedded --strict`, run `grdr doctor`, and test SaaS cell portability/reconciliation invariants in `grdr-saas`.
