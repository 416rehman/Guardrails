# Adopters

Organisations that run Guardrails ADR and agreed to be listed. Nothing in
the product reports its use, so this list is the only record of adoption.

## Adopters

No adopter is listed yet.

## How to be listed

Open a pull request that adds one line under "Adopters": your
organisation, how you run the product (standalone, self-hosted server,
hosted, or embedded) and since when.

An unaffiliated production adopter, as COVENANT.md defines it, also
confirms in its line that it has no ownership, employment, contract or
funding relation with the steward, and that it has run the product on at
least 25 endpoints or one server installation for at least 90 consecutive
days. Those rows count towards the covenant's transfer trigger.
