# A02 lifecycle-delta (version 1.0.0)

Concept:
List every flag, nullable field, status value, counter or timer this diff adds to an existing lifecycle. Show the transition-table delta and any new state that has no exit.

Looks in: any diff touching a machine listed in `docs/state-machines/`; compare it with that machine's transition table.

Evidence: the added declaration or assignment, and the row of the machine's table it changes.

Claim: "The diff adds X to lifecycle L, creating state or combination S that no row of `docs/state-machines/L.md` produces or leaves." A transition or type in the diff that covers S refutes it.

Class keys: `lifecycle-delta:new-flag`, `lifecycle-delta:new-nullable`, `lifecycle-delta:new-status-value`, `lifecycle-delta:new-counter`, `lifecycle-delta:new-timer`, `lifecycle-delta:state-without-exit`.

Artefact: the transition-table delta in the runner's pull-request comment.

Closure guidance: a type (the new data moves into the state that owns it) or a transition test that drives every new row, the exit included.
