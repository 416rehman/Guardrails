# I02 build-supply-chain (version 1.0.0)

Concept:
List build scripts, procedural macros, install scripts, unpinned CI actions, network fetches at build time, and skills or plugins not pinned by commit (SD-12).

Looks in: `build.rs`, `.github/`, `.agents/`, the marketplace manifest (`.agents/kit/marketplace.toml`).

Evidence: the script, macro, action reference or manifest entry.

Claim: "Item I at P runs at build or install time unpinned, or fetches from the network." A full-SHA pin or a vetted record refutes it.

Class keys: `build-chain:build-script`, `build-chain:proc-macro`, `build-chain:install-script`, `build-chain:unpinned-action`, `build-chain:build-fetch`, `build-chain:unpinned-skill`.

Artefact: pinning list.

Closure guidance: a lint (zizmor, `cargo-deny`, or the `kit check` pin rule).
