# A03 reachable-illegal-transitions (version 1.0.0)

Concept:
For machine {name} in `docs/state-machines/`, construct the shortest event sequence that reaches each transition marked impossible. Include retries, duplicate delivery, parallel tool calls, process restart and update hand-over. Express each sequence as a failing test or a Quint trace.

Looks in: the machines the A01 run of the same trigger upheld; parallel tool calls against `state_seq` ordering (design/12 section 9).

Evidence: the code that accepts each event of the sequence, and the transition the table marks impossible.

Claim: "Events E1 to En from state S reach impossible transition T of machine {name}." A guard or type that rejects one event of the sequence refutes it.

Class keys: `illegal-transition:retry`, `illegal-transition:duplicate-delivery`, `illegal-transition:parallel-calls`, `illegal-transition:restart`, `illegal-transition:update-handover`, `illegal-transition:event-order`.

Artefact: reproducers. Put the sequence in `closure_proposal.detail` as a test body or Quint trace; the prover writes it in a scratch worktree and the runner runs it.

Closure guidance: a test: the failing test, or the Quint trace replayed with `quint-connect`, passing after the fix. Where the machine is still implicit, A01's type closure comes first.
