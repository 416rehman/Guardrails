# A06 dual-sources-of-truth (version 1.0.0)

Concept:
Find each fact stored or derived in more than one place. Name the authority, every writer and reader, and an event sequence after which the copies disagree.

Looks in: assurance level versus record (the level must come from the published function only); effective policy versus the fail-safe table versus native compile-down (D-12); install journal versus the agent's files on disk; device versus server enrolment state.

Evidence: each copy's declaration or write site, and the reader that trusts a copy.

Claim: "Fact F is held at A and B; after events E1 to En they disagree and reader R acts on the stale copy." A single derivation, or a sync that runs on every one of those events, refutes it.

Class keys: `dual-truth:stored`, `dual-truth:derived`, `dual-truth:cross-process`.

Artefact: fact, copies, authority and sync path.

Closure guidance: a type that derives the copy from the authority, or a test that drives the sequence and asserts the copies agree.
