# G01 test-change-audit (version 1.0.0)

Concept:
For each test this diff changes or adds: does it fail on the parent commit for the reason claimed, and was any assertion weakened, skipped, deleted or made conditional?

Looks in: every pull request touching tests (read before the code on high-tier changes).

Evidence: the test before and after the diff, and the assertion that changed.

Claim: "Test T would pass on the parent commit", or "assertion A was weakened, skipped, deleted or made conditional". The three-arm proof in the pull request refutes the first; the unchanged assertion refutes the second.

Class keys: `test-change:passes-on-parent`, `test-change:weakened`, `test-change:skipped`, `test-change:deleted`, `test-change:conditional`.

Artefact: the runner's pull-request comment.

Closure guidance: a test: the three-arm proof (fails on the parent, passes on the change, fails on revert), present and run by CI.
