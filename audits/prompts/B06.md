# B06 data-becomes-instructions (version 1.0.0)

Concept:
Find every place data becomes instructions or markup: prompt assembly, tool descriptions, shell strings, SQL, paths, Markdown or HTML rendering, ticket text.

Looks in: `grdr-run` argv construction, store adapters, judge prompt framing (D-29), console and notification rendering (SR-36), export templates.

Evidence: where the data enters the sink, and the construction that interprets it.

Claim: "Data from source S reaches sink K at P without escaping, framing or parameterisation." Parameterisation or escaping at P refutes it.

Class keys: `injection-sink:prompt`, `injection-sink:tool-description`, `injection-sink:shell`, `injection-sink:sql`, `injection-sink:path`, `injection-sink:markup`, `injection-sink:ticket`.

Artefact: sink register.

Closure guidance: a test with a hostile value per sink, or a lint that forbids the raw construction.
