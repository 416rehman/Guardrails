# Y03 variant-hunt (version 1.0.0)

Concept:
Given incident {ref} and the commit that fixed its root cause, find every other place in the repository where the same pattern occurs.

Looks in: the whole repository.

Evidence: the fixed pattern in the fix commit, and each other occurrence.

Claim: "The pattern fixed for {ref} occurs again at P." A difference that makes P safe refutes it.

Class keys: `variant:same-pattern`, `variant:near-pattern`.

Artefact: variant list.

Closure guidance: a test per variant, or a lint that finds the pattern.
