# Y04 incident-to-library (version 1.0.0)

Concept:
Given incident {ref}, name the prompt that should have found it, the wording change that would have made it do so, and the seeded defect to add to `audit-bench`.

Looks in: the library (`audits/`), the ledger.

Evidence: the prompt's wording, and the root-cause code of the incident.

Claim: "Prompt X should have found {ref}; wording change W would have made it; seed S reproduces the defect." A ledger run of X that did find it refutes it.

Class keys: `library-gap:missed`, `library-gap:no-prompt`.

Artefact: library change proposal.

Closure guidance: a decision record, with the bench seed it names added to `audit-bench`. The incident review stays open until both are merged or explicitly declined.
