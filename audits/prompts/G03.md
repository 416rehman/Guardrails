# G03 surviving-mutants (version 1.0.0)

Concept:
For each mutant that survived the last full `cargo-mutants` run, name the behaviour no test asserts and the test that would kill it.

Looks in: the mutation report, worst crates first. With no report yet, return "not applicable" with that reason.

Evidence: the mutated line, and the tests that cover it without asserting the behaviour.

Claim: "Mutant M at P survives because no test asserts behaviour B; test T would kill it." An existing test that kills M refutes it.

Class keys: `surviving-mutant:boundary`, `surviving-mutant:return-value`, `surviving-mutant:deleted-call`, `surviving-mutant:negated-condition`, `surviving-mutant:arithmetic`.

Artefact: test proposals.

Closure guidance: a test that kills the mutant.
