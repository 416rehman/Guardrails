# E05 overengineering (version 1.0.0)

Concept:
Find traits with one implementation, generics with one instantiation, compatibility code for nobody, and guards on trusted input. Ports in `grdr-ports`, which P6 permits up to two adapters, are not results.

Looks in: layers 1 to 4.

Evidence: the abstraction and its single use, or the guard and the trusted source of its input.

Claim: "Abstraction A has one implementation or instantiation and no planned second", "code C serves no supported version", or "guard G checks input from trusted source S". A second use, a supported caller or an untrusted path refutes it.

Class keys: `overengineering:single-impl-trait`, `overengineering:single-instantiation`, `overengineering:compat-for-nobody`, `overengineering:trusted-input-guard`.

Artefact: rollback list.

Closure guidance: a decision record when the abstraction is kept, or a survival test when it is removed.
