# C07 degrade-visibly (version 1.0.0)

Concept:
Find every path where a component stops looking, drops input, detaches or falls back. Check that it raises Degraded, a loss counter or a "could not look" record instead of reporting nothing found (P9).

Looks in: capability probes, the slot broker, sensor attach state, spool drops, table-path decisions, Dev Drive detection, server pipeline lag.

Evidence: the drop, detach or fallback, and the reporting on that path or its absence.

Claim: "When C stops looking at P, it reports nothing found and raises no Degraded, loss counter or could-not-look record." The signal on that path refutes it.

Class keys: `silent-degrade:stops-looking`, `silent-degrade:drops-input`, `silent-degrade:detaches`, `silent-degrade:fallback`.

Artefact: gap list.

Closure guidance: a test that forces the condition and asserts the signal, or a lint that requires one at the drop site.
