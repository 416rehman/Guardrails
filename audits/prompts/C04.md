# C04 implicit-transactions (version 1.0.0)

Concept:
Find multi-step operations that can succeed partway and leave state inconsistent, with no rollback or compensation.

Looks in: agent configuration writes and uninstall restore (D-49), `grdr join` and `leave`, pack activation, update A/B slot commit, server migrations.

Evidence: the steps in order, and the point after which a failure leaves state half-applied.

Claim: "Operation O fails after step N and leaves state S with no rollback or compensation." A journal, rollback or idempotent re-run on that failure refutes it.

Class keys: `partial-op:no-rollback`, `partial-op:compensation-gap`.

Artefact: step and compensation table.

Closure guidance: a test that injects a fault after each step and asserts a consistent state.
