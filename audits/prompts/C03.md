# C03 panic-paths (version 1.0.0)

Concept:
Find `unwrap`, `expect`, indexing, unchecked arithmetic, `unreachable!` and recursion reachable from untrusted input.

Looks in: `grdr-fastpath` (must never abort a host), `grdr-ffi`, privileged programs, `grdr-llm-proto`, `grdr-mcp-proto`, normalisers in `grdr-core::analyze`.

Evidence: the panicking expression, and the untrusted input that reaches it.

Claim: "Input I from source S reaches the panic at P." A bound or check on every path from S refutes it.

Class keys: `panic:unwrap`, `panic:expect`, `panic:indexing`, `panic:arithmetic`, `panic:unreachable`, `panic:recursion`.

Artefact: fuzz-target list.

Closure guidance: a test (a fuzz target with a corpus entry that reaches P) or a lint that denies the construct in that crate.
