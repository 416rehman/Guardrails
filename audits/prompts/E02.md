# E02 scattered-rules (version 1.0.0)

Concept:
Find one policy rule implemented in more than one place and show where the copies differ.

Looks in: fail-closed classes in Cedar packs, the core's floor policy, the fail-safe table and native compile-down; the Mode ladder in CLI, console, tray and desktop.

Evidence: each copy of the rule, and the line where they differ.

Claim: "Rule R is implemented at A and B, and they differ on input I." Generation of B from A refutes it.

Class keys: `scattered-rule:diverged`, `scattered-rule:duplicated`.

Artefact: rule map.

Closure guidance: a type (one source generates the rest) or a differential test across the copies.
