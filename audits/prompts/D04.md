# D04 deadline-paths (version 1.0.0)

Concept:
List every path with a latency budget and find blocking I/O, DNS, synchronous locks, allocation in loops, logging or model calls on it.

Looks in: the shim's 250 ms acknowledgement (or a valid update-handover marker's deadline, never beyond 2 s, D-14), 1,800 ms verdict and 1,950 ms watchdog; engine evaluation under 1 ms; proxy under 20 ms added; tier 0 `decide`.

Evidence: the budgeted entry point, and the blocking or costly call on its path.

Claim: "Path P with budget B calls C, which can block or exceed B." Proof that C is bounded, or off the path, refutes it.

Class keys: `deadline:blocking-io`, `deadline:dns`, `deadline:sync-lock`, `deadline:alloc-in-loop`, `deadline:logging`, `deadline:model-call`.

Artefact: budget table.

Closure guidance: a test (an instruction-count gate on the path) or a lint that denies the call there.
