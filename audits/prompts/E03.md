# E03 deletion-pass (version 1.0.0)

Concept:
Delete code, branches, flags and workarounds until a test or mutation check fails. Propose removing everything that survives, with the reason it existed.

Looks in: the whole scope. The deletion is reasoned, not performed: the finder edits nothing (preamble rule 1), and the prover checks survival in a scratch worktree.

Evidence: the code that survives deletion, and the commit, comment or design line that says why it was added.

Claim: "Item I can be removed with no test or mutation check failing; it existed for reason R, which no longer holds." A test that fails without I, or a reason that still holds, refutes it.

Class keys: `removable:code`, `removable:branch`, `removable:flag`, `removable:workaround`.

Artefact: removal list.

Closure guidance: a test: survival tests that show the behaviour without the item, landed with its removal.
