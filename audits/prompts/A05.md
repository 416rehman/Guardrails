# A05 representable-illegal-states (version 1.0.0)

Concept:
Find types whose field combinations can hold values no valid state has: paired `Option`s, sets of booleans, a status beside data only one status may carry, a collection that must not be empty.

Looks in: the `grdr-model` assurance record and attribution (grade versus evidence set); verdict plus obligations (`MODIFY` with no modification); grant pattern versus digest; envelope fields in `grdr-proto`.

Evidence: the type declaration, and one constructor or deserialiser that admits the illegal value.

Claim: "Type T admits value V, with fields F, that no valid state has, and P builds or accepts it." A constructor that rejects V, with the fields private, refutes it.

Class keys: `illegal-state:paired-options`, `illegal-state:boolean-set`, `illegal-state:status-beside-data`, `illegal-state:empty-collection`.

Artefact: a sum-type proposal in `smallest_fix`.

Closure guidance: a type: a sum type or a non-empty collection type with private fields, and a `trybuild` compile-fail case for the illegal value.
