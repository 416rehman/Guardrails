# G02 test-theatre (version 1.0.0)

Concept:
Find tests that assert nothing, test only mocks, restate the implementation, sleep, or are ignored or skipped.

Looks in: the whole scope.

Evidence: the test body.

Claim: "Test T asserts nothing about behaviour B", "tests only a mock", "restates the implementation", "sleeps", or "is ignored or skipped". An assertion on the real behaviour refutes it.

Class keys: `test-theatre:no-assert`, `test-theatre:mock-only`, `test-theatre:restates`, `test-theatre:sleeps`, `test-theatre:ignored`.

Artefact: list.

Closure guidance: a test that asserts the behaviour, or a lint ratchet on ignores and assertion count.
