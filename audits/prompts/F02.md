# F02 undeclared-public-change (version 1.0.0)

Concept:
List behaviour changes in public crates (layers 0 to 2, `grdr-ffi`, `grdr-wasm`) that `cargo-semver-checks` cannot see and that no changelog entry or RFC declares.

Looks in: public crates.

Evidence: the changed behaviour, and the changelog or RFC that should declare it.

Claim: "Public item I changes its default, error contract, ordering or meaning with no changelog entry or RFC." The entry or the RFC refutes it.

Class keys: `undeclared-change:behaviour`, `undeclared-change:default`, `undeclared-change:error-contract`, `undeclared-change:ordering`.

Artefact: list.

Closure guidance: a decision record (an RFC, D-61) or a test that pins the behaviour.
