# K02 dead-ends (version 1.0.0)

Concept:
Find every path where a user or agent meets a denial, error or empty state with no next step, including a classifier or model denial that does not degrade to Ask or a one-step exception.

Looks in: CLI errors, `grdr doctor` hints, the first-run scan, the setup list, approval timeouts.

Evidence: the denial, error or empty state, and what it offers next.

Claim: "At P the user or agent meets D with no next step." A hint, an Ask or a one-step exception on that path refutes it.

Class keys: `dead-end:denial`, `dead-end:error`, `dead-end:empty-state`, `dead-end:no-degrade`.

Artefact: dead-end list.

Closure guidance: a test that reaches the state and asserts a next step.
