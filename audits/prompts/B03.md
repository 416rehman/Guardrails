# B03 layering-intent (version 1.0.0)

Concept:
Compare the code with `architecture.toml` and the lint table in design/03. Find what the ARCH lints cannot see: logic in layer 4 programs that is more than wiring, `Effect` bypasses, patterns other code is copying, over-wide public surface.

Looks in: `programs/`, `grdr-core` module imports, `surfaces.toml`.

Evidence: the code that breaks the intent, and the line of `architecture.toml`, `surfaces.toml` or design/03 it breaks.

Claim: "Item I in layer L does X, which the layering intent at P forbids and no ARCH lint catches." A lint that already fails on it, or a design rule that allows it, refutes it.

Class keys: `layering:program-logic`, `layering:effect-bypass`, `layering:copied-pattern`, `layering:wide-surface`.

Artefact: violation list.

Closure guidance: a lint: a new `ARCH-NNN` rule whose message states the fix, with a fixture that triggers it.
