# H04 stale-agent-instructions (version 1.0.0)

Concept:
Find instructions in `AGENTS.md`, `REVIEW.md`, skills and hook messages that are stale, contradict a lint, or that the current model over-applies.

Looks in: `.agents/`, `REVIEW.md` per area.

Evidence: the instruction, and the lint, code or run record that makes it stale or over-applied.

Claim: "Instruction I at P is stale, contradicts lint L, or is over-applied in run R." Current code or a run showing it holds refutes it.

Class keys: `stale-instruction:stale`, `stale-instruction:contradicts-lint`, `stale-instruction:over-applied`.

Artefact: instruction diff.

Closure guidance: a lint that replaces the instruction, or a decision record that keeps or removes it.
