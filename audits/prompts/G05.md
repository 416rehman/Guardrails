# G05 oracle-independence (version 1.0.0)

Concept:
Find tests whose expected values come from the code under test: snapshots accepted from current output, golden vectors generated by the same build, reference models that share code with the implementation.

Looks in: `grdr-policy-ref` (must share no code with `grdr-core::policy`), insta snapshots, `conformance/` vectors, normaliser fixtures that do not come from real shells (D-10).

Evidence: the expected value, and where it came from.

Claim: "Test T's oracle comes from the implementation at P, so it cannot catch defect D." An independent source for the expected value refutes it.

Class keys: `oracle:snapshot-from-output`, `oracle:golden-from-build`, `oracle:shared-code-reference`, `oracle:synthetic-fixture`.

Artefact: list.

Closure guidance: a test with an independent oracle, or a dependency lint on reference crates.
