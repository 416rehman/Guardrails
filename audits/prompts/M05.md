# M05 model-verdict-reach (version 1.0.0)

Concept:
Trace every value of model or heuristic origin to every decision it can reach. Sources: judge outputs, review-stage results, `injection-suspected` and other advisory labels, the session risk integer, `agent-suspected`, the agents' own classifier denials, natural-language policy drafts. Report two kinds of path. (a) The value can produce ALLOW, a grant, a declassification, a suppression, a finding closure, an exception, Mode down, or a change to egress default-deny, protected paths, agent-config writes, credential brokering, the kill switch, tenant isolation or failure mode (P2). (b) The value reaches an Ask or Block verdict on the synchronous path, where advisory labels must evaluate as absent (D-09, D-24), or ends a denial without a route to Ask or a one-step exception (D-44).

Looks in: `grdr-core::detect` advisory labels and their Cedar projection, `grdr-core::session` origin checks, the judge back-end trait (D-29), `review` and `grdr-judge-*` back ends, natural-language authoring (design/12 section 12), D-44 degradation in `grdr-agents` encoders.

Evidence: the source of the value, each hop of the path, and the sink.

Claim: "Value V of model or heuristic origin from source S reaches sink K along path P (kind a or b)." A type barrier on P (`EnforcingLabel`, below) or a check that drops V before K refutes it.

Class keys: `model-reach:allow`, `model-reach:grant`, `model-reach:declassification`, `model-reach:suppression`, `model-reach:finding-closure`, `model-reach:exception`, `model-reach:mode-down`, `model-reach:p2-control`, `model-reach:sync-verdict`, `model-reach:denial-dead-end`.

Artefact: `docs/assurance/model-reach.md`: source, path, sink, kind.

Closure guidance: a type or a test, never a decision record. The type is `EnforcingLabel` in `grdr-model`, built only inside `grdr-core::session` from a `DeterministicFact`, which a checked conversion refuses for heuristic and model origins; the Cedar and daemon label projections take only `EnforcingLabel`, advisory labels are a separate type with no conversion, and `trybuild` compile-fail cases prove both. Report the paths types cannot cover: the pack validator's origin check, grants, suppressions and the console.
