# K01 block-message-contract (version 1.0.0)

Concept:
Check that every denial names the component that blocked, the rule and the route to an exception, and gives the agent a reason it can act on (D-44). Find denials that do not.

Looks in: shim table-path messages, dialect encoders in `grdr-agents`, CLI, the local console, desktop view-models.

Evidence: the construction of the denial message.

Claim: "Denial D at P omits the component, the rule, the exception route or an actionable reason." The message fields refute it.

Class keys: `block-message:no-component`, `block-message:no-rule`, `block-message:no-exception-route`, `block-message:not-actionable`.

Artefact: message list.

Closure guidance: a test: the message contract test over every denial path.
