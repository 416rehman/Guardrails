# M01 fail-open-paths (version 1.0.0)

Concept:
For every enforcement point in {scope}, list each way it can fail: error, timeout, panic, abort, missing or expired configuration, unparseable input, unknown harness version, peer gone, resource limit, update in progress. For each, state what the action receives (deny, allow or hold), whether that matches the rule class's declared `on_failure` and the shim's fail-safe table, and whether an open outcome raises Degraded and emits an event. An open outcome with no event is severity 1.

Looks in: the `grdr-hook` watchdog at 1,950 ms (exit 0 with Degraded unless `--strict`); the table path, its built-in minimal table, and the fail-safe table compiled on the device and signed with the device-local artefact key; the update-handover marker deadline (never beyond 2 s, D-14); per-handler vendor flags; the core's floor policy; engine error mapping; proxy and `gateway` deny on evaluation error (SR-40, SR-46); zero silent fail-open (SR-14, SR-15); Codex hooks that run the tool on every failure (design/07 section 10); the crash-loop ladder (SR-16); update verification (stays on the current slot).

Evidence: the failure branch at the enforcement point and the outcome it returns, the declared `on_failure` or fail-safe table row, and the event emission or its absence.

Claim: "When enforcement point E meets failure F, the action receives outcome O, which differs from the declared `on_failure` or fail-safe row R", or "O is open and raises no Degraded and no event". The branch returning the declared outcome, with the event, refutes it.

Class keys: `fail-open:error`, `fail-open:timeout`, `fail-open:panic`, `fail-open:abort`, `fail-open:config`, `fail-open:unparseable`, `fail-open:harness-version`, `fail-open:peer-gone`, `fail-open:resource-limit`, `fail-open:update`.

Artefact: `docs/assurance/fail-modes.md`, generated and compared with conformance results (design/07 section 10).

Closure guidance: a test only: a fault-injection case in `grdr-conformance` that forces F and asserts the declared outcome and the event. Never a decision record.
