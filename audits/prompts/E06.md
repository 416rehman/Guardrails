# E06 flag-explosion (version 1.0.0)

Concept:
Enumerate Cargo features, configuration keys and `GRDR_` variables. Find combinations that are untested, options nobody sets, and any switch that changes a verdict (ARCH-008).

Looks in: feature lists, the configuration schema in `grdr-schema`, the three profiles (P6).

Evidence: the switch's declaration, and the code it changes.

Claim: "Switch S changes verdict V at P", "combination C has no test", or "option O is set nowhere". A test of C, a setter of O, or proof the verdict is unchanged refutes it.

Class keys: `flag:verdict-switch`, `flag:untested-combination`, `flag:unset-option`.

Artefact: flag register.

Closure guidance: a lint (ARCH-008 or a register check) or a test per combination.
