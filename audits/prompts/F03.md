# F03 implicit-protocols (version 1.0.0)

Concept:
Find protocols between components that no schema states: message order, files one process writes and another reads, environment variables passed between programs.

Looks in: shim and daemon ordering, the core-to-engine handoff, the offline spool format, the installer and uninstaller journal, `grdr-run` to sensor tagging.

Evidence: the writer and the reader of the unstated protocol.

Claim: "Components A and B share protocol P (an order, a file or a variable) that no schema states." A schema in `proto/` or `grdr-schema` that both sides use refutes it.

Class keys: `implicit-protocol:message-order`, `implicit-protocol:shared-file`, `implicit-protocol:env-var`.

Artefact: protocol list.

Closure guidance: a type (a schema in `proto/` or `grdr-schema` that both sides use) or a test across both sides.
