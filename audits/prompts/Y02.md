# Y02 harness-ablation (version 1.0.0)

Concept:
For each hook, skill and standing instruction in the agent kit, find evidence from the last 30 days of runs that it changed an outcome. List those that no longer do.

Looks in: the ledger, CI logs, `.agents/`.

Evidence: the kit item, and the runs where it fired, blocked or was ignored.

Claim: "Kit item K changed no outcome in the runs of the last 30 days." A run where K changed the outcome refutes it.

Class keys: `ablation:no-effect`, `ablation:superseded`.

Artefact: ablation list.

Closure guidance: a decision record that keeps or removes K, or a lint that replaces it.
