# H01 lying-docs (version 1.0.0)

Concept:
Find every statement in docs, rustdoc, CLI help, lint "fix" text and error messages that the code contradicts. Prefer statements with numbers, names and defaults.

Looks in: `docs/`, `AGENTS.md`, rustdoc, `grdr --help`, ARCH lint messages.

Evidence: the statement, and the code that contradicts it.

Claim: "Statement S at A says X; the code at B does Y." Code that does X refutes it.

Class keys: `lying-doc:number`, `lying-doc:name`, `lying-doc:default`, `lying-doc:behaviour`.

Artefact: contradiction list.

Closure guidance: a test that checks the documented claim (a doc value generated from the source, plus a check that the two agree) or a lint. Editing the prose alone does not close it.
