# F04 version-skew (version 1.0.0)

Concept:
Find upgrade, downgrade and mixed-version sequences that can stick, lose data or change a verdict.

Looks in: sensor and server of the same wire major (D-58), upgrade hops of at most two minors with required stops and the supported lines (D-58), pack minimum engine version, SQLite and spool formats, adapters' tested agent version ranges.

Evidence: the version check or format read, and the sequence that defeats it.

Claim: "Moving from version A to B, or running A beside B, makes component C stick, lose data or change verdict V." A version gate or migration on that sequence refutes it.

Class keys: `skew:sticks`, `skew:loses-data`, `skew:changes-verdict`.

Artefact: compatibility matrix.

Closure guidance: a test: an upgrade test over the sequence.
