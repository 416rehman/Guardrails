# K04 claims-versus-record (version 1.0.0)

Concept:
Find text in UI, docs or CLI output that claims more than the assurance record supports: "protected" in the User profile, "unforgeable" for G0 or G1, an agent's own permission prompt presented as an approval at any grade (spine section 3), boundary language for a request (P1).

Looks in: strings, docs, `grdr status`, console tiles.

Evidence: the text, and the assurance-record field it overstates.

Claim: "Text T at P claims X; the assurance record supports only Y." Text derived from the record refutes it.

Class keys: `overclaim:protected-in-user-profile`, `overclaim:unforgeable-low-grade`, `overclaim:agent-prompt-as-approval`, `overclaim:boundary-for-request`.

Artefact: claim list.

Closure guidance: a test (each string checked against the record) or a lint on the wording.
