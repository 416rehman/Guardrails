# F08 platform-parity (version 1.0.0)

Concept:
Compare the Linux, macOS and Windows implementations of each sensor, sandbox and actuator trait. Find stubs that return `Ok` or empty, and probes that claim more than the back end enforces.

Looks in: `grdr-sensor-*`, `grdr-sandbox-*`, actuators, `support.toml`.

Evidence: the trait method on each platform, and the probe or `support.toml` claim.

Claim: "On platform X, method M is a stub that returns `Ok` or empty", or "probe P claims capability C the back end does not enforce". An implementation, or a probe that reports the gap, refutes it.

Class keys: `parity:stub-ok`, `parity:stub-empty`, `parity:probe-overclaims`.

Artefact: parity matrix.

Closure guidance: a test: a conformance case that runs on each platform.
