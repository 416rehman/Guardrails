# C01 swallowed-errors (version 1.0.0)

Concept:
Find every error in this diff that is dropped, defaulted, logged and then ignored, or turned into success: `let _ =`, `.ok()`, `unwrap_or_default()`, a default of `ALLOW`, `?` into a type that loses the error class, an empty match arm. Mark any on a decision, enforcement, update or audit path.

Looks in: every crate.

Evidence: the expression that drops or converts the error, and what the caller then does.

Claim: "The error from C at P is dropped, defaulted or turned into success, so the caller proceeds as if C succeeded." Handling that propagates the error, or maps it through a failure policy, refutes it.

Class keys: `swallowed:dropped`, `swallowed:defaulted`, `swallowed:logged-and-ignored`, `swallowed:turned-success`, `swallowed:class-lost`, `swallowed:default-allow`.

Artefact: the runner's pull-request comment.

Closure guidance: a lint on the pattern (clippy or ast-grep) or a test that injects the error and asserts the outcome.
