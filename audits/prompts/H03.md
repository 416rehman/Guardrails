# H03 newcomer-traps (version 1.0.0)

Concept:
With only the repository, what would a new engineer or agent most likely get wrong in {scope}, and which file would have misled them?

Looks in: per-crate `AGENTS.md`, `docs/architecture/`.

Evidence: the misleading line, and the code that shows the truth.

Claim: "A newcomer reading F would do X, which breaks Y." A statement in the same file that prevents X refutes it.

Class keys: `trap:misleading-file`, `trap:missing-guide`, `trap:surprising-convention`.

Artefact: trap list.

Closure guidance: a lint or test that catches the mistake, or a decision record that removes the trap.
