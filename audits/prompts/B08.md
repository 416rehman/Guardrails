# B08 privacy-schema-drift (version 1.0.0)

Concept:
Find fields with no `data_class`, code that groups or scores by principal, per-person metrics, and paths that skip the capture-level filter on the device.

Looks in: `grdr-proto` options, `grdr-schema-lint`, the pack validator, export down-converters (D-51, P8).

Evidence: the field declaration, or the grouping, metric or capture path.

Claim: "Field F has no `data_class`", "P groups or scores by principal", or "path P sends captured data without the capture-level filter". The option or the filter on that path refutes it.

Class keys: `privacy-drift:no-data-class`, `privacy-drift:principal-scoring`, `privacy-drift:per-person-metric`, `privacy-drift:filter-bypass`.

Artefact: field list.

Closure guidance: a lint: a `grdr-schema-lint` rule with a fixture that triggers it.
