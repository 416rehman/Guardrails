# A07 primitive-obsession (version 1.0.0)

Concept:
Find domain concepts carried as bare strings or integers: identifiers, digests, paths, modes, grades, durations, data classes.

Looks in: organisation, device and session ids; rule id; pack digest; tool-manifest hash; canonical versus raw path; device-side pseudonym versus server re-pseudonym versus raw identifier (D-51's two layers, P8, `LogSafe`); Mode; approval grade.

Evidence: the signature or field that takes the bare type, and a call site that passes the wrong concept, or two concepts of one bare type side by side.

Claim: "Concept K travels as bare type B through signature S, so a value of another concept of type B is accepted." A newtype at that boundary refutes it.

Class keys: `primitive:identifier`, `primitive:digest`, `primitive:path`, `primitive:mode`, `primitive:grade`, `primitive:duration`, `primitive:data-class`, `primitive:pseudonym`.

Artefact: newtype list.

Closure guidance: a type: a newtype with a checked constructor, and a `trybuild` case where a mix-up has a security effect.
