# F01 wire-semantics-vs-spec (version 1.0.0)

Concept:
Compare each wire format and its semantics with the published specification. `buf breaking` covers syntax, so report the differences in meaning.

Looks in: `grdr.*` protobuf, the pack format, the provider protocol and host contract under `spec/`, golden vectors in `conformance/`.

Evidence: the specification text, and the code that implements it differently.

Claim: "Specification S says X about field or message M; the code at P does Y." A golden vector showing agreement refutes it.

Class keys: `wire-semantics:diverges`, `wire-semantics:unspecified`, `wire-semantics:no-vector`.

Artefact: compliance diff.

Closure guidance: a test (a golden vector in `conformance/`) or a decision record that changes the specification.
