# B07 secret-and-content-leaks (version 1.0.0)

Concept:
Find secrets, captured content or raw identifiers that can reach logs, `Debug` output, error messages, crash reports, metrics labels or support bundles. Also find missing zeroisation and non-constant-time comparison.

Looks in: `LogSafe` derivations, error `Display` impls, `grdr support-bundle`, `grdr-crypto` callers, approval memory of agents' settings files (research/21).

Evidence: the value's type or field, and the output site that formats it.

Claim: "Value V of class C reaches output O at P unredacted", "V is not zeroised on drop", or "V is compared in variable time at P". A redacting type or a constant-time comparison on that path refutes it.

Class keys: `leak:secret`, `leak:captured-content`, `leak:raw-identifier`, `leak:no-zeroise`, `leak:non-constant-time`.

Artefact: leak list.

Closure guidance: a type (`LogSafe`, or a secret newtype that redacts and zeroises) or a lint on the formatting site.
