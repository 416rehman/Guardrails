# E01 near-duplicates (version 2.0.0)

Concept:
Find near-duplicate functions and parallel abstractions for one concept, and name the one to keep.

Looks in: the duplicate-code report of gate V27 (`target/verify-logs/jscpd/`) first, then per-agent translators in `grdr-agents`, shared logic in the three OS sensors, view-models used by CLI, console and desktop.

Evidence: the duplicates side by side, and the lines where they differ.

Claim: "Items A and B implement concept K twice; keep A." A behaviour difference the concept requires refutes it.

Class keys: `near-duplicate:function`, `near-duplicate:abstraction`.

Artefact: consolidation list.

Closure guidance: a type (one shared implementation the others call) or a differential test that holds them equal until they merge.
